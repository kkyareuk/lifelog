평행도시 개인정보처리방침

시행일: 2026년 7월 29일

생활권과 캐릭터 데이터는 공개 프로필로 제공되지 않습니다. 다만 Firebase 프로젝트 운영자는 기술적으로 저장 데이터에 접근할 권한을 가질 수 있으며, 서비스 제공·오류 대응·보안·법적 의무 이행 목적 외에는 열람하지 않습니다. 정확한 집 주소 대신 역이나 동네처럼 넓은 범위를 입력해 주세요.

1. 처리하는 정보

  • Google 로그인 정보: 계정 식별자, 표시 이름, 이메일, 프로필 사진
  • 이용자가 입력한 정보: 캐릭터 설정, 이미지, 관계, 루틴, 생활권, 장소 후보
  • 기기 저장 정보: 테마와 API 연결 설정, 백업 정보

2. 이용 목적

로그인, 기기 간 데이터 동기화, 캐릭터 시뮬레이션 제공, 오류 대응과 보안 유지에 사용합니다.

3. 보유 기간과 삭제

계정 데이터는 이용자가 삭제를 요청하거나 서비스가 종료될 때까지 보관될 수 있습니다. 브라우저의 로컬 데이터는 이용자가 브라우저 저장공간을 삭제하면 제거됩니다.

4. 외부 처리 서비스

인증과 동기화에는 Google Firebase, 지도와 장소 정보에는 Google Maps Platform이 사용될 수 있습니다. 해당 사업자의 처리 정책이 함께 적용됩니다.

5. 이용자의 권리

이용자는 설정 내보내기·불러오기를 사용할 수 있으며, 자신의 데이터 열람·정정·삭제를 요청할 수 있습니다. 실제 운영 전에는 운영자 연락처와 삭제 요청 방법을 이 문서에 반드시 추가해야 합니다.

6. 안전성

접근 권한 제한, 인증, 전송 구간 보호 등 합리적인 보호조치를 적용합니다. 이용자는 API 키나 로그인 정보를 타인에게 공유하지 않아야 합니다.

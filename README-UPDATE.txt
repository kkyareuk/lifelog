LIFELOG Google Places API 업데이트

1. GitHub 저장소 최상단의 index.html과 sw.js를 이 폴더의 파일로 교체합니다.
2. 사이트를 새로고침한 뒤 테마 탭의 Google Maps · Places API에 키를 입력합니다.
3. Google Cloud에서 Maps JavaScript API와 Places API (New)를 활성화해야 합니다.
4. API 키의 웹사이트 제한에 GitHub Pages 주소(예: https://아이디.github.io/저장소명/*)를 등록하세요.

기존 캐릭터 데이터는 같은 사이트 주소와 브라우저에서 유지됩니다. API 키는 백업 JSON에 포함되지 않습니다.

# 집 벽·가구 덧그리기 틀

## 벽

- 완성 크기: 1536×1024 px
- 빨간 점선 위쪽 48 px: 상단 몰딩 영역
- 빨간 점선 아래쪽 130 px: 하단 걸레받이 영역
- 가운데 세로선은 좌우 반복 연결을 확인하는 보조선입니다.
- 앱에는 `wall-redraw-reference.png`가 기본 손그림 벽으로 적용되어 있습니다.
- 새 그림을 돌려주실 때 파일 전체 크기와 위·아래 기준선만 유지하면 같은 자리에 바로 교체할 수 있습니다.

## 가구

- 전체 크기: 1536×1024 px, 6열×4행
- 한 칸: 256×256 px
- 갈색 실선: 잘라낼 셀 경계
- 청록 점선: 가구가 들어갈 안전 영역
- 45도 원근 없이 정면 또는 정확한 옆면으로 그립니다.
- 현재 가구 그림은 참고·덧그리기용이며 앱에는 적용하지 않았습니다. 앱은 당분간 기존 이모지 가구를 사용합니다.

## 가구 순서

1행: 소파 / 안락의자 / 커피 테이블 / TV / 낮은 TV장 / 책장

2행: 식탁 / 식탁 의자 / 냉장고 / 주방 수납장 / 가스레인지 / 싱크대

3행: 싱글 침대 / 커플 침대 / 옷장 / 서랍장 / 책상 / 책상 의자

4행: 샤워 부스 / 욕조 / 변기 / 욕실 세면대 / 신발장 / 캣타워

## 생성 참고

ImageGen 내장 모드로 정면·옆면 가구 24종과 손그림 벽을 제작했습니다. 가구 프롬프트는 ‘투명 배경, 6×4, 정면 또는 정확한 측면, 45도·아이소메트릭 금지, 따뜻한 크림·월넛·청록 팔레트’를 기준으로 했습니다.

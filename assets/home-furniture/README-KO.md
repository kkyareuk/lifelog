# 가구 스프라이트 덧그리기 원본

`source/furniture-redraw-atlas-01.png`부터 `04.png`까지가 덧그리기용 투명 원본입니다.

- 각 파일은 가로 5칸 × 세로 4칸이며, 한 칸에 가구 하나가 들어 있습니다.
- 캔버스 크기와 5×4 칸 위치를 바꾸지 않은 채 원하는 그림으로 덮어 그려 주세요.
- 배경은 지우거나 칠하지 말고 투명하게 유지해 주세요.
- 완성한 네 파일을 그대로 보내 주면 같은 위치의 게임용 개별 PNG 80개로 다시 잘라 교체할 수 있습니다.
- 가구 이름과 개별 파일 연결은 `furniture-sprite-manifest.json`에서 확인할 수 있습니다.

## 실제 배치 칸

가구의 점유 크기는 그림 파일의 크기가 아니라 `furniture-layout.js`의 `FURNITURE_FOOTPRINTS`가 결정합니다. 작은 소품은 1×1, 냉장고·거울처럼 긴 가구는 1×2, 소파는 3×1, 식탁·커플 침대·피아노처럼 큰 가구는 최대 3×2를 사용합니다. 덧그린 그림으로 교체해도 이 배치 크기는 그대로 유지됩니다.

## 다시 자르기

Pillow가 설치된 Python에서 아래처럼 실행합니다.

```powershell
python scripts/build-furniture-sprites.py 원본1.png 원본2.png 원본3.png 원본4.png
```

투명 PNG를 넣으면 그대로 분리하고, 생성기의 밝은 체크 배경이 남은 PNG를 넣으면 외곽과 연결된 체크 영역만 투명화한 뒤 분리합니다.

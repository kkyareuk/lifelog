# 멤버 차단과 퇴장 선택

2026-09-09: dev 기능 추가. 기준 배포본 Android 305 / 1.0.272, TestFlight 1.0.269 (32). 이 변경의 신규 앱 빌드 및 서버 배포는 아직 미진행.

- 멀티 멤버의 계정 차단 창에서 방장·관리자는 차단하기 또는 차단하고 퇴장시키기를 선택한다.
- 퇴장은 선택한 그룹에만 적용하고, 해당 멤버의 캐릭터는 개인 마을로 돌아간다. 계정 차단은 전체 그룹에 적용한다.
- 서버에서 권한을 다시 확인하고 차단·퇴장·캐릭터 복귀를 하나의 트랜잭션으로 처리한다. 방장 퇴장은 금지한다.
- 일반 멤버에게는 계정 차단만 표시한다. 영어·일본어 문구도 추가했다.
- 검증: check-block-remove.cjs, check-user-safety295.cjs, check-leave-retry30.cjs, qa-block-remove.mjs 통과. 실제 기기/운영 서버의 새 기능은 미검증.

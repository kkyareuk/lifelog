# 서랍마을 v1.0.182 / code 195

## 캐릭터 성격과 기분

- 캐릭터 설정 9페이지의 제목, 설명, 선택 항목을 하나의 흐름 레이아웃으로 묶어 작은 Android 화면에서도 글자가 겹치지 않게 했다.
- 8페이지의 사회성, 인지 방식, 판단 방식, 계획 성향, 활동 속도, 부지런함, 정리 습관, 갈등 방식, 애정 표현, 생활 리듬, 유머 성향이 상황별 기분 계산과 행동 주도권, 생활 로그의 말투·행동 묘사에 반영되도록 했다.
- 새 기분 사유 문구는 한국어·영어·일본어로 함께 제공한다.

## 건물 드레스코드

- 건물 설정의 `유니폼 착용 필수` 항목과 이벤트를 제거했다.
- 이전 저장 데이터에 해당 값이 남아 있어도 건물 드레스코드에서는 사용하지 않는다. 일정의 유니폼 설정과 옷장의 유니폼 분류는 유지한다.

## 집 생활 애니메이션

- 집을 처음 열 때 이미 가구를 사용 중인 캐릭터는 가구 위치에서 바로 사용 동작으로 표시한다.
- 집 화면을 계속 보고 있는 동안 실제 행동 장소가 바뀔 때만 걷기 단계를 재생한다.
- 화면 진입 직후 과거 이동을 다시 재생해 캐릭터가 먼 곳으로 순간이동했다가 가구로 되돌아오던 문제를 수정했다.

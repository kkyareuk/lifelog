# 서랍마을 1.0.175 / 188 개발 기록

## 옷장 UI와 옷 등록

- 캐릭터 전체 설정 11페이지를 사전과 같은 검색·필터·3열 아이콘 목록 구조로 다시 배치했다.
- 옷 카드와 추가 카드를 책 안쪽 프레임에 맞추고, 휴대폰 384×854 화면에서 열과 글자가 겹치지 않는지 확인했다.
- 옷의 별도 분류 입력은 제거하고, 기분 태그에 `유혹적임`을 추가했다.
- 색, 재질, 분위기는 각각 별도 버튼을 눌러 여러 개 고르는 창으로 열리도록 바꿨다.
- SD 아이콘은 정사각형, LD는 세로 전신 비율로 표시해 그림이 눌리지 않게 했다.

## 드레스코드와 자동 의상

- 건물과 주간·월간 일정에 드레스코드를 설정할 수 있다.
- 격식, 필수 유니폼, 허용 색, 권장 재질, 분위기를 저장한다.
- 현재 장소와 일정의 드레스코드를 옷장의 상황·기분·계절 조건과 함께 비교해 홈 SD·LD를 선택한다.

## 기분과 캐릭터성

- 기분 점수에 현재 행동, 장소와 마을 분위기, 집의 정돈·아름다움, 동행 관계, 업무 스트레스, 옷과 드레스코드 일치 여부를 함께 반영한다.
- 과묵하고 감정을 절제하는 캐릭터는 좋은 상황에서도 갑자기 들뜨기보다 `만족함`으로 표현한다.
- 중립 상태도 평온함 하나로 고정하지 않고 차분함·무덤덤함·평온함으로 나뉜다.

## 마을 행동과 건물 그림

- 마을 인물은 식사, 음악, 공부, 업무, 운동, 대화, 쇼핑, 진료, 청소, 휴식 등 현재 행동에 맞는 표시와 움직임을 사용한다.
- 건물 안에 있는 인물도 단순 정지 대신 현재 행동을 보여준다.
- 행동 표시의 불필요한 검은 점과 건물 뒤 그림자를 제거했다.
- 임시 빨간 지붕 집을 목록에서 제거하고 사용자 원본의 빨간 지붕 집만 사용한다.
- 카페, 병원, 피아노 음악당, 공원, 빨간 지붕 집은 원본 시트의 각 그림 경계에 맞춰 다시 추출했다. 병원의 흰색 건물 면은 유지하고 바깥쪽 흰 배경만 투명 처리한다.

## 성능과 번역

- 마을 건물·인물과 옷장 카드의 렌더링 범위를 제한하고, 행동 애니메이션은 합성 가능한 transform/opacity 중심으로 구성했다.
- 새 옷장, 드레스코드, 기분, 마을 행동 문구를 영어·일본어 화면에도 이어서 적용했다.

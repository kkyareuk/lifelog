# iOS 운영판 출시 진행 · 2026-09-07

게임 기준은 운영 main 841787a / Android 1.0.215.10 (264)입니다. dev266 기능을 포함하지 않습니다.
출시 브랜치: codex/ios-production264. iOS 버전 1.0.215, 빌드14.

## 확인한 현재 차단 사항
- 사용자가 유료 앱 계약 상태를 ‘사용자 정보 대기 중’으로 확인했습니다. 실제 사업자/세금/은행 정보는 사용자가 입력하고 계약 활성화를 확인해야 합니다.
- 동일한 앱 내 구입 키의 Apple API 인증: Sandbox 거래조회4040010(존재하지 않는 거래로 검사), Production HTTP401. 실제 과금이나 거래를 생성하지 않았습니다. Production 인증 성공 및 실제 구매·지급 성공으로 보고하지 않습니다.
- 상품3개 모두 MISSING_METADATA. 마을/캐릭터 상품의 현재 draft version에서 localizations 및 images가 비어 있음을 API로 확인. 일부 메타데이터를 입력했다는 사용자 답변. 가격/판매국가를 임의 변경하지 않습니다.
- Google 로그인과 StoreKit을 운영판 iOS에 연결했지만 Apple 로그인 제공자 활성화 여부는 사용자 답변 대기입니다. Apple 로그인 구현/프로파일 및 앱 내 계정 삭제, 기기 구매·복원·환불 QA가 완료돼야 심사 준비 완료로 판정합니다.
- 기존 내부 테스트 전용 업로드 제한을 별도 운영 iOS 브랜치에서만 해제했습니다. App Store에서 선택 가능한 빌드를 업로드하지만, 자동 심사 제출이나 자동 공개는 수행하지 않습니다.

## 결제 서버 보완
Production을 먼저 조회하고 Apple의 명시적인4040010일 때만 Sandbox로 재조회합니다. 인증오류401은 Sandbox로 우회하지 않습니다. 서명·앱ID·계정·상품 검증 및 환경별 지급 분리를 유지합니다. 운영 지급/테스트 분리/인증 오류/중복 지급/환불 재전송 검사 통과. 계약 문제 해결 전 운영 서버 설정은 Sandbox에서 변경하지 않았습니다.

## 사용자가 입력할 상품 한국어 문구
- 마을1개: 이름 ‘마을 1개 추가’, 설명 ‘계정에 마을 슬롯 1개를 추가합니다.’
- 캐릭터5명: 이름 ‘캐릭터 5명 추가’, 설명 ‘계정에 캐릭터 슬롯 5개를 추가합니다.’
- 응원선물: 이름 ‘서랍마을 응원 선물’, 설명 ‘서랍마을 개발을 응원하는 일회성 선물입니다.’
각 상품의 가격·판매국가·심사용 스크린샷도 완료해야 합니다. 실제 제공 혜택과 최종 대조합니다.

## 잊지 않을 dev 디자인 요청
첨부 화면의 멀티 목록 상단 초대 코드/참여하기, 전체/내가 만든 그룹, 검색 입력, 관계탭 그룹 버튼을 앱 그림체와 어울리게 재설계합니다. iOS 운영판 출시를 먼저 하라는 요청에 따라 후속 작업으로 유지합니다.

# Android 1.0.215.8 · code 255

## 긴급 결제 안전 보강

- Google Play가 여러 구매 옵션을 반환해도 목록의 첫 항목을 그대로 사용하지 않고, 별도 오퍼 ID가 없는 기본 구매 옵션 중 즉시 소유되는 정상 유료 옵션만 선택합니다.
- 0원 옵션, 할인 옵션, 대여 및 사전 주문 옵션은 앱이 직접 결제창에 전달하지 않습니다.
- 결제 콜백에서 구매 완료 상태, 앱 패키지, 요청 상품 일치를 확인한 뒤에만 서버 검증으로 넘깁니다.
- 상점도 정상 유료 옵션을 확인한 상품만 구매 가능 상태로 표시합니다.
- 서버의 Google Play 영수증 확인, 구매 토큰 중복 방지, 완료 주문 확인 뒤 지급 흐름은 그대로 유지됩니다.

## Play Console의 0원 주문 해석

제보 화면은 고객 결제액이 0원이지만 정가 1,200원과 예상 순수익 840원이 함께 표시됩니다. 이는 취소 주문이나 앱 장바구니 한도로 가격이 0원이 된 형태와 다르며, Google 측 쿠폰·크레딧·Google 부담 프로모션이 적용된 주문과 일치합니다. 핫픽스는 앱이 무료 또는 할인 구매 옵션을 능동적으로 고르는 경로를 차단하되, Google이 차액을 부담해 개발자에게 정상 정산하는 결제는 막지 않습니다.

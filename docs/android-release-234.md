## 변경 사항

- 태블릿 세로 화면이 721px 이상 데스크톱/태블릿 레이아웃으로 잘못 넘어가던 분기를 제거하고, 캐릭터·집·마을 및 기타 하위 화면이 휴대폰용 반응형 구조를 그대로 사용하게 했습니다.
- 세로 관찰 화면의 이름·직업 위치를 프로필 사진 바로 옆으로 맞추고, 좌우·하단 메뉴 라벨 높이를 고정해 한글이 한 글자만 보이거나 잘리지 않게 했습니다.
- 태블릿 가로 캐릭터 화면은 기존 iPad식 왼쪽 캐릭터 목록을 유지하면서 오른쪽에 휴대폰과 같은 주민등록증·책·빠른설정·전체설정·관리 버튼을 모두 표시합니다.
- 태블릿 가로 전체설정은 기존처럼 양쪽 책장을 동시에 펼치고 두 페이지씩 이동합니다.
- 가로 관찰 홈에서 화면 전체를 덮던 마을 지도를 원래 iPad식 왼쪽 지도 패널로 되돌리고, 선택한 캐릭터 장면과 상태 카드는 오른쪽 패널에 유지했습니다.
- 실제 마을 탭의 가로 화면은 화면을 채우되 아이콘 뒤 흰 사각형과 장식 테두리는 계속 숨기며, 세로 마을은 휴대폰 구조를 사용합니다.

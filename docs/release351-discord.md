서랍마을 1.0.318 (351) 업데이트

이번 업데이트에서 변경된 주요 내용을 안내드립니다.
1.0.307 (340) 이후의 변경 사항을 모아 안내드려요.

✨ 새로운 기능
- 성향에 도덕성을 추가하고, 다양한 상황 질문과 개성 있는 답변을 늘렸어요.
- 질문에 어울리는 답이 없다면 ‘캐릭터스러운 답이 없어요!’로 의견을 남길 수 있어요.
- 멀티방마다 이름과 프로필 사진을 따로 정할 수 있어요.

🔧 개선 사항
- 화면 전환과 전체설정 페이지 이동, 질문 답변 저장에서 불필요하게 반복하던 처리를 줄였어요.
- 캐릭터를 누르면 성격과 관계에 어울리는 상호작용이 먼저 나와요. 다른 행동도 같은 메뉴에서 골라요.
- 상호작용 문장과 효과를 각 캐릭터의 성격과 마음에 맞게 다듬었어요.
- 말투를 예문과 함께 고르는 전용 팝업을 추가하고, 비슷한 말투 일부를 통합했어요.
- 통계에 마을 성향 평균과 기울어진 방향을 표시해요. 미설정 성격은 순위에서 제외하고, 정확히 50일 때만 균형형으로 표시해요.
- 공지와 주고받은 우편이 자동으로 사라지지 않아요. 일반 우편은 ‘선택 삭제’를 누른 뒤 골라서 정리할 수 있어요.

🎨 UI/UX
- 마을에서 집의 ‘들어가기’를 누르면 해당 집 화면으로 이동해요.
- 캐릭터 설정에서 제목과 말투 선택창이 겹치던 부분을 조정했어요.
- 크레딧을 이름 검색과 3열 명단으로 정리했어요.
- 방 사진·바닥 사진을 지우거나 기본 모습으로 돌아가는 설정과 안내를 보완했어요.

🐛 오류 수정
- 일시적인 네트워크 오류 뒤 멀티 마을이 사라진 것처럼 보이는 문제를 보완했어요.
- 멀티 재가입 시 기존 방장·관리자 권한을 우선 확인하도록 수정했어요.
- 멀티에서 본인 소유 집의 편집 권한과 방 설정·삭제·가구 이동을 보완했어요.
- 주인이 없는 방이 ‘주인만 출입’ 설정 때문에 막히지 않도록 공용 공간으로 판단해요. 직접 지정한 출입 대상은 유지해요.
- 접촉 설정 때문에 실행할 수 없는 행동을 방 출입 문제로 안내하던 문구를 수정했어요.
- 질문 답변의 저장·복원과 질문 표시 누락, 일정이 생활 습관보다 뒤로 밀리던 문제를 수정했어요.
- 일부 영어·일본어 설정 표시와 안내를 보완했어요.

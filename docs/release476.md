# 서랍마을 내부 1.0.424 (476)

## 변경
- 마을 배경을 서랍마을 / 아르켄발트로 정리하고 각각 설명 제공. 아르켄발트는 1400년대 프랑스·잉글랜드 생활을 섞은 가상 국가이며 중세 DLC에 연결. 시대에 따른 음식 제한은 제거. 중세 요리의 DLC 구매 조건은 유지.
- 판타지 요리는 DLC 전까지 새 요리 선택과 자동 요리에서 전부 숨김. 레시피 데이터·기존 보유 수량·진행 중 요리는 보존.
- 마을 배경음은 배경 설정과 독립적으로 서랍마을 / 아르켄발트 선택. 아르켄발트 일반 화면은 선술집 / Medieval Waltz 랜덤 선택, 다음 곡 즉시 반복 회피. 집은 Irish Celtic Medieval Music, 마을은 Quiet Repose. 음량·음소거 유지, 재렌더 재시작 방지. 원곡/가공/라이선스 기록은 audio476.md.
- 로그 펼치기/접기에 menu-selection, 썰기에 knife-cut 발췌 반복, 끓이기에 새 water-boils 음원과 음량 보정.
- 새로 요리한 음식은 조리대·탁자 또는 주방에 배치. 거주 캐릭터가 이동·먹기·냉장 보관 가능, 소유자는 버리기 가능. 실온18시간, 냉장4배 느린 부패, 이동 시 신선도 초기화 방지. 상한 음식은 어두운 색·냄새 표시, 섭취 불가.
- 요리 경험치 단계 조정과 같은 요리 반복 보상 완화. 기존 레벨 진행률 보존. 경제 시스템을 사용하는 캐릭터는 허기·일정·잔액·권한을 확인하여 시간대별 자동 식사/요리. 캐릭터별 시작 시각 분산, 한 끼 중복 실행 방지.
- 욕구별 빈도와 활동 시간 조절, 선택형 수면 시각 분산. 용변은 도착 후10초. 중단 전 회복분 유지, 종료 이후 초과 회복 방지. 집·마을 캐릭터 및 수동 활동 표시 경로에 진행 막대.
- 개인 직업 독립 화면: 직업/직급·선택 지급주기 급여·출근 시각·근무 요일·동료3열·관계·승진 안내. 승진 안내는 조건 설명이며 자동 승진은 추가하지 않음. 편집 버튼은 전체설정3페이지에 연결.

# 서랍마을 내부 1.0.432 (484)

## 변경
- 사용자가 캐릭터에게 보낸 쪽지를 생활 시뮬레이션에 연결. 집 생활 로그에 도착과 읽는 장면을 각각 표시.
- 집에서 깨어 있고 자유로운 동안 약 1분간 읽음. 수면·식사·근무·사용자 지정 행동을 우선하며 중간에 방해받으면 남은 읽기 시간을 이어서 진행.
- 다 읽은 쪽지는 재시작 후에도 중복해서 읽지 않고 보낸 우편함에 읽음 표시. 유저가 보낸 우편을 열거나 모두 읽음을 누르는 것과 구분.
- 개인 마을 및 멀티 마을 지원. 기존 개인 보낸 우편함의 보관된 쪽지 및 멀티 최근300개 우편 내 사용자→캐릭터 쪽지를 연결. 멀티 이행은 그룹당 한 번 수행.
- 멀티 공용 생활 데이터에는 쪽지 ID·도착 시각·집과 읽기 상태만 저장. 제목/본문을 공용 집 로그에 노출하지 않음. 사용자 간 편지와 공지는 자동 캐릭터 읽기 대상에서 제외.
- 새 문구 한국어·영어·일본어 제공.

## 변경
- 식사 효과음의 무한 반복 제거. 관찰하는 캐릭터 화면 한 번 방문당 한 번 재생. A→B→A는 A에서 다시 한 번 재생한다. 같은 화면 재렌더·백그라운드 복귀·음소거 전환으로 반복하지 않는다. 음료의 기존 행동별 정책은 유지한다.
- 침대 그림 크기에 비례해 아이콘이 최소10px까지 작아지던 계산에 표시 최소 크기 추가. 게임 플레이 설정에서 가구 비율(기존),24,32(기본),40px 선택. 침대 기준 위치·회전은 유지한다.
- 새 캐릭터 생성에 성격4종 × 생활3종 프리셋 선택. 수치와 실제 행동 성향을 함께 적용한다. 이름·사진·기존 캐릭터는 덮어쓰지 않는다.
- 연락 설정의 캐릭터 선택을 버튼→3열 선택창으로 변경. 개인·멀티 캐릭터 선택의 기존 식별자와 저장 흐름 유지.
- 편지 쓰기의 발신자·수신자를 검색 가능한3열 선택창으로 선택. 기존 폼 상태 및 비동기 수신자 권한 목록을 유지하며 실제 발송은 사용자 제출로만 진행.

- 읽을 수 없는 local-media 참조 대신 유효한 프로필 사진/봉투 이미지 사용. 공유 프로필의 문자열·객체 표현 모두 처리. 아이콘 로딩 실패 시 등록된 프로필 사진 사용. 제보의 젠할린 실제 계정 자료는 확인하지 않았으며 원본 이미지가 없을 때 복원했다고 주장하지 않는다.

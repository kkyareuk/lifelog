# iOS 출시 준비 확인 — 2026-09-08

사용자는 유료 앱 계약 활성화를 알렸습니다. 오늘 App Store Connect 및 Firebase 관리 API로 아래 상태를 재확인했습니다. 심사 제출은 하지 않았으며 출시 준비 완료가 아닙니다.

## 완료
- 기존 업로드 1.0.215/build14: VALID, APP_STORE_ELIGIBLE. 편집 중인 iOS 출시 버전에 연결되어 있습니다.
- 공개 방식은 AFTER_APPROVAL로 설정되어 있습니다. 실제 공개는 Apple 심사 승인 이후입니다.
- 상품 3개(마을 1개, 캐릭터 5명, 응원 선물)의 한국어·영어·일본어 표시 이름/설명 총 9개를 등록하고 재조회했습니다. 이 상품 문구 번역은 각 언어 3/3 완료입니다.
- 상품별 가격 일정과 판매 가능 지역 설정 레코드는 존재합니다. 기존 가격/지역은 변경하지 않았습니다.
- 운영 결제의 서명·계정·상품 검사, 중복 지급 방지, Sandbox 지급 분리, 환불 재전송, 인증 오류 시 우회 금지 자동 검사 통과(dev 결제 서버 코드 기준).

## 제출 전 남은 사항
- 상품 3개의 심사용 스크린샷이 없습니다. 상품 상태는 MISSING_METADATA입니다.
- Firebase 관리 API: google.com enabled=true, apple.com NOT_FOUND. Apple 로그인 제공자 설정이 없습니다. 빌드14도 Google 로그인만 연결되어 있습니다.
- 빌드14에서 앱 내 계정 삭제 기능이 확인되지 않았습니다. 실제 사용자 데이터 삭제·Apple 토큰 해제까지 구현/검증해야 합니다.
- 심사 연락처 필드는 채워져 있지만 로그인 필요=true, 심사용 계정 및 심사 메모는 비어 있습니다. 임의 계정정보를 넣지 않았습니다.
- 빌드14의 수출 규정(usesNonExemptEncryption) 응답은 null입니다. 배포 코드의 암호화 사용 검토 후 정확히 답해야 합니다.
- 앱 개인정보·연령등급·모든 필수 기기 스크린샷 등 전체 제출 항목은 아직 최종 검증하지 않았습니다.
- Store Server API: 동일 IAP 키로 Sandbox 거래 조회는 4040010(존재하지 않는 테스트 식별자), Production 거래 조회와 최근 알림 이력 조회 모두 HTTP401입니다. 원인을 계약 문제로 단정하지 않습니다. 실제 거래를 생성하거나 결제/지급 완료로 표시하지 않았습니다.
- 운영 서버 환경은 Sandbox로 유지되어 있습니다. Production 인증과 실제 구매 검증을 해결한 뒤 전환해야 합니다.
- iOS14 경고가 있는 기존빌드의 최소OS를 다음 제출용 빌드에서 검토해야 합니다. 기존빌드는 업로드 실패가 아닌 처리 완료 상태입니다.

## 버전 경계
- 이 iOS 후보는 운영264 기반의 별도 포트입니다. 이후 운영274 핫픽스와 dev280/예정281 개선을 포함하지 않습니다.
- 최신 배포용 소스 범위를 맞추고 위 미완료 사항을 수정한 새 iOS 빌드가 필요합니다. build15 이상은 업로드 직전 Apple에서 중복 여부를 확인해야 합니다.
- Android 운영main274, 개발판280은 이번 iOS 메타데이터 작업에서 변경/배포하지 않았습니다. 요청된 멀티·태블릿·효과강도 개발판281 작업은 미완료 상태로 유지합니다.

읽기 전용 재확인: ASC 환경변수가 준비된 상태에서 `node scripts/ios-release-readiness.mjs`. 보고서는 개인정보/토큰을 저장하지 않으며 ready를 자동으로 true로 만들지 않습니다.

## 후속 · Apple 키 파일 확보 및 Firebase 연결 완료
- 사용자가 Downloads 경로를 제공했고 AuthKey_BXUJ9VYS35.p8 파일(257 bytes)을 확인했습니다. P-256 EC 개인키 형식 검사 통과. 키 내용은 로그/저장소에 출력하지 않았습니다.
- 승인된 기존 Firebase 관리 세션을 갱신한 후 Apple 제공자를 생성했습니다. enabled=true, native clientId 및 허용 bundleIds=com.drawervillage.app, codeFlowConfig의 Team ID/Key ID 등록 후 재조회 일치 확인.
- 웹용 Services ID·리디렉션 등록은 이번 단계에서 만들지 않았습니다. 현재 설정은 iOS 네이티브 앱에 한정하며 실제 Apple 로그인·코드 교환·토큰 해제 성공은 아직 실기기 검증 전입니다.
- 키 사본은 프로젝트/OneDrive 밖 LocalAppData/DrawerVillage/ios-secrets에 저장하고 현재 Windows 사용자와 SYSTEM 접근으로 제한, 원본과 SHA256 일치 확인. 원본 Downloads 파일은 보존했습니다.
- 기존 키 DP73N3TJ7H/895DH37Y2U의 최종 폐기 상태는 이번 단계에서 재확인하지 않았습니다. 신규 키 정상 동작 검증 후 불필요한 키 정리 필요.
- 빌드14에 로그인 버튼/계정삭제가 자동 적용되는 것은 아닙니다. 앱 코드, Apple entitlement, 서명 프로파일 및 새 빌드 검증이 남았습니다. 결제 검증용 IAP 키와 환경은 변경하지 않았습니다.
- iOS/Android 새 빌드·심사 제출 미실행. 기존 앱 및 전체 번역 진행률 변경 없음. 상품 문구 영어·일본어 각3/3 완료 유지.

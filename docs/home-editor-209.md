- 옷장 프레임 하단을 올려 페이지 넘김 영역과 분리.
- 마을 건물별 캐릭터 검색에 현재 이벤트 캐시 재사용. 숨겨진 집 로그는 열 때 생성. 집 편집 중 관찰 장면 갱신 중지.

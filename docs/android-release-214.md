## 이번 변경

- iOS에서 수정했던 태블릿 관계 뒤로가기, 집·방 정보 크기, 닫힌 편집 패널 노출, 마을 세로/가로 배치를 Android 준비 자산에도 포함했습니다. 태블릿의 세로 방향 강제 잠금을 해제했습니다.
- 2인 침대의 실제 그림 영역을 기준으로 두 캐릭터 얼굴을 베개 위치에 표시합니다. 이미지가 읽히거나 방 크기가 달라질 때 다시 맞춥니다.
- 집 제목 옆에 집 외형 그림을 표시합니다.
- 전체설정의 책 원화를 유지하면서 세로 공간을 늘려 페이지 번호와 넘김 버튼이 종이 안에 들어오게 했습니다. 태블릿에서도 빠른설정/전체설정 진입 버튼을 표시합니다.
- 공식 관계 목록의 카드, 사진, 글자와 편집 버튼을 정돈했습니다.
- 첫 캐릭터 만들기는 장식 노트 없이 간결한 입력 창으로 열리며 이름을 입력해 저장할 수 있습니다.
- 상점 분류 버튼의 그림자·글자 테두리를 제거해 글자가 두 겹처럼 보이지 않게 했습니다.
- 가구창의 방 선택/방 종류 분류를 제거했습니다. 검색/가구 종류로 찾은 가구를 원하는 방에 끌어놓으면 해당 방과 좌표를 자동 계산합니다. 기존 가구도 방을 넘나들 수 있고, 선택 메뉴로 다른 층에 보낼 수 있습니다. 방이 아닌 곳에 놓거나 취소하면 새 가구를 추가하지 않습니다.

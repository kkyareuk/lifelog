# Android 개발 빌드 1.0.212 (code 229)

- 브랜치: `dev`
- 빌드 표식: `20260906dev229`
- 상태: APK/AAB 생성 및 로컬 검증 완료. Google Play에는 업로드하지 않음.

## 변경 사항

- 앱 시작 및 Google 계정 전환 시 계정의 클라우드 저장본을 먼저 내려받고 병합한 뒤 게임 화면을 엽니다.
- 로그인 전에 만든 첫 캐릭터는 첫 명시적 Google 로그인 때 새 계정 저장 영역으로 인계하고, 게스트 복구본도 유지합니다.
- Android의 백업 파일 내보내기를 브라우저 링크 대신 네이티브 MediaStore 저장으로 연결해 `다운로드/DrawerVillage`에 UTF-8 JSON을 저장합니다.
- 침대에서 함께 시간을 보내는 두 캐릭터를 베개 위치에 적정 크기로 한 번만 표시하고, 이불 아래 전용 애니메이션과 하나의 공유 이름·행동 카드를 사용합니다.
- 로그 요약의 프로필 사진을 정사각 원형 프레임에 꽉 차게 표시합니다.
- 관찰 화면의 기존 제목 위치·크기를 기준으로 집과 마을 제목을 맞췄습니다.
- Android 태블릿의 기존 가로·세로 레이아웃을 복원하고, 캐릭터 오른쪽 정보 패널과 가로 전체설정 양면 책을 사용합니다. 마을 장식 선택 테두리와 깨진 관찰 배치를 수정했습니다.
- 찻잔·음식 소품 애니메이션과 설정 선택 개수의 즉시 갱신을 포함합니다.

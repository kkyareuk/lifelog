# 공개 1.0.444 (496) 준비

사용자 명시 요청: Android 프로덕션 및 Apple 심사. 직업·재산·요리 모두 공개, 요리 과정 애니메이션 제거. 이전 내부495를 그대로 승격하지 않고 새 공개496 빌드를 검증한다.

## 변경
- 반복된 자율 행동은 최근20개 장면과 비교하여 새로운 후보를 우선 선택.
- 마을 편집 중 건물 드래그를 화면 이동이 가로채지 않도록 수정.
- 영어 간편설정의 좁은 화면 줄바꿈·열 너비 수정.
- 상점 기본 순서: 캐릭터, 마을, 응원선물, 광고제거, 용량(지원 플랫폼).
- 멀티와 개인 집의 방 편집 화면 통일, 편집 중 층 추가. 개인 저장과 멀티 저장은 분리 유지.
- 홈 직업란에 실제 직업명과 오늘의 업무 함께 표시.
- 멀티 안내는 초대코드 → 마을 슬롯1개 필요 및 실제 잔여 슬롯 표시.
- 이메일 오류 제보 복원, 사용자가 메일 앱에서 내용·진단정보를 확인하여 전송. 기존 익명 제보 유지.
- 요리 제목은 음식명 + 만드는 중, 과정 애니메이션 제거. 요리 기능·소리·단계 로그 유지.
- 건물 밖 공동 식사를 다른 장소로 오판하여 혼자 쉬는 로그가 되던 오류 수정.

## 검증 및 미확인
Chrome/WebKit 개인·멀티 방 동일 필드/저장·개인 데이터 격리·층 추가·메일 초안·건물 드래그 검사 통과. 공유 생활 200명·식사 양측·일정 경계·취소 검사 통과. 결제/중복 지급 구조 검사 통과. 200명 초기 계산은 PC 약37초로 대규모 마을의 성능 개선 완료를 의미하지 않는다.
기존 일정 검사2건은 소스문자열/옛 버전 고정 검사 실패이며 실제 공유 일정 경계 검사는 통과.
마을 슬롯 미지급 제보(pth1006,467)는 계정UID/주문번호 없이 개인 거래 특정 불가. 해결/추가지급 완료로 표시하지 않는다. 오류화면 제보 역시 상세 미제공.
신규 문구 KO/EN/JA 포함. 전체 번역률은 최종 집계 예정.

## 배포
서명 빌드·스토어 제출·서버 반영 진행 중. 완료 여부는 검증 후 기록한다.

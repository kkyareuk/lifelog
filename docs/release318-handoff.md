# 318 / 1.0.285 — dev 준비판

- 성향 8축의 양측 비교로 구체적인 관찰과 반응을 구성. 명시적 시선 우선, 무관심에 억지 짜증/애정 추가하지 않음. 통제욕으로 표시명 변경.
- 멀티 구성원에 새 캐릭터 카드와 가져오기/직접 생성 선택. 개인 데이터에 생성하지 않고 기존 서버 슬롯·구성원 검사를 사용.
- 생성 재시도에 같은 ID 사용. 이사 중 진행 안내·중복 클릭 차단. 후보 목록 로딩/실패 구분.
- 이전 그룹 구독의 늦은 오류 무시, 강제 재연결 지원.

검증: 성향 96개 다국어 사례, 명시적 시선 100회, 기존 모순 640장면, 관계317·교류312·공유312 회귀검사. 생성 서버 모의 트랜잭션: 권한/마을/슬롯/중복. 구독 오류 경쟁 조건 모의검사. 실제 Chrome에서 구성원 컴포넌트 3언어 × 384/1180, 로딩과 동일 ID 재시도. 웹 빌드·Android 모듈 포함 검사·release AAB 성공, 288개 자산 바이트 대조·AD_ID 없음.

전체 정적 번역률 EN 2240/2944 (76.1%), JA 2239/2944 (76.1%). 이번 신규 UI/로그는 3언어 포함.

Play 업로드, 운영 웹/공유 서버 배포, iOS 서명·IPA는 미실행. 멀티 전체 이용 불가 제보는 구체 증상이 없어 해당 계정에서 재현하지 못함. 공유 서버용 runtime은 준비했으며 배포 시 반영 필요. 운영 main은 유지하고 dev에 커밋.

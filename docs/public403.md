# 403 · 공개 배포 준비

- 기준: Play 공개391(1.0.339), 내부402(1.0.350). dev에서 수정. game main은 기존 배포 기준을 보존.
- Android/iOS 공개용 1.0.351(403): 광장 진입은 준비 중 안내, 참여 게임 조회도 생략. 공개 웹도 같은 정책.
- 내부404는 광장 기능 활성화. 빌드 시 채널을 명시하며 기본은 공개. 계정 권한을 이 표시 플래그로 대체하지 않음.
- 과묵한 직설체의 젠장 및 대응 감탄사 제거. 샘플·편지 원본 및 생성 대사 경로 반영.
- 전체 설정 기본 페이지를 스크롤 가능한 2열 폼으로 변경. 성별/성지향 아래 대명사 버튼, 팝업은 유지. 페이지 넘김 버튼 여백 확보.
- 홈 멀티 선택/마을 화면 선택 버튼 간격, 전체 읽음 버튼, 광장·서랍 순서 수정.
- 멀티 생성 전 개인 roster가 서버 core와 같으면 전체 클라우드 업로드 생략. 변경·누락·이동 revision 차이는 기존 업로드 경로를 거침. 서버 슬롯/멤버/승인 검사는 유지.
- 실제 기기 네트워크에서 생성 시간 개선율은 측정하지 않음. 테스트는 격리 fixture 사용.
- Apple391은 현재 심사 대기. 403 업로드 처리 확인 후 제출 교체 예정.

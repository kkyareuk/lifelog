# v1.0.179 / code 192

## 캐릭터 정서와 생활 장면

- 최종 기분 점수가 음수인데 낙천적 성향 때문에 `기분 좋음`으로 표시되던 분기를 제거했다.
- 낙천성은 부정 사건의 영향과 회복 강도를 완충하지만, 표시 감정은 최종 점수 구간을 따른다.
- 화남·슬픔·긴장·피곤·지루함은 다음 자유 행동을 각각 거리 두기, 조용한 회복, 작은 일 확인, 휴식, 활동 전환으로 바꾼다.
- 선택된 행동은 다시 다음 기분 계산에 들어가 같은 감정이 무한히 고정되지 않는다.
- 짧은 말씨름은 12분, 일반 상호작용은 25분 뒤 끝나며 같은 상대와는 60분 동안 즉시 재시작하지 않는다.
- 심야에는 아침 식사·식사 준비 장면을 만들지 않고, 야식 습관을 선택한 캐릭터만 야식 장면을 사용할 수 있다.

## 캐릭터 책과 옷장

- `기분과 정서 성향` 입력 영역을 머리말 아래로 내려 겹침을 없앴다.
- SD 아이콘과 LD 사진 배치를 수치 슬라이더 대신 직접 끌기, 두 손가락 확대·축소 및 회전 방식으로 바꿨다.
- 옷장의 `필수 유니폼`을 `유니폼으로 등록`으로, 건물·일정 설정을 `유니폼 착용 필수`로 구분하고 작동 방식을 설명했다.

## 언어

- 새 UI 문구와 감정별 생활 행동은 한국어·영어·일본어를 함께 제공한다.

## 검증

- 음수 기분 점수가 긍정 감정명으로 표시되지 않는 회귀 검증을 추가했다.
- 긍정 사건·갈등·피로 사건이 서로 다른 감정 종류를 만드는지 검증한다.
- 직접 배치, 상호작용 종료, 심야 식사 제한, 버전 및 캐시를 함께 검사한다.

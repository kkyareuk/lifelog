# 서랍마을 1.0.198 (5) iOS 테스트 업데이트

이번 업데이트에서 변경된 주요 내용을 안내드립니다.
이전 TestFlight 빌드 4 대비 변경사항입니다.

🎨 UI/UX
- 태블릿에서 집·방 정보의 검색창, 제목, 사진 크기를 조정했습니다.
- 집 옆 사진의 비율을 유지하고, 지도·캐릭터·메뉴 간격을 정리했습니다.
- 캐릭터가 한 명일 때 관계 화면에 뒤로가기와 캐릭터 추가 안내를 제공합니다.

🐛 오류 수정
- 태블릿을 세로로 돌리면 마을 화면과 버튼 배치가 깨지던 문제를 수정했습니다.
- 닫힌 집 편집창과 구성원 목록이 집 화면에 함께 표시되던 문제를 수정했습니다.
- 세로 집 화면에서 방 아래에 큰 빈 공간이 생기던 문제를 수정했습니다.

📌 테스트 안내
- TestFlight에서 **1.0.198 (5)**로 업데이트해 주세요.
- 가로·세로 회전, 관계·방 정보의 뒤로가기, 저장 후 앱 재실행을 확인해 주세요.
- 로그인·클라우드 동기화·구매는 아직 지원하지 않는 로컬 플레이 테스트 버전입니다.

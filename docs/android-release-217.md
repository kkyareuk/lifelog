# Android 1.0.202 · versionCode 217

2026-09-05 `dev` 준비판. 이전 [216 준비판](android-release-216.md)의 변경사항을 모두 포함합니다. 운영 main/웹사이트/iOS 배포 및 Play Console 업로드는 변경하지 않았습니다.

## 파일

- 바로 설치용 APK: `drawer-village-v1.0.202-code217-dev-debug.apk`
- Play Console 업로드용 AAB: `drawer-village-v1.0.202-code217-dev-release.aab`
- APK SHA-256: `637ED5513CA8296E1FA82AC82D7E515FAD4F142218BCB2C10C824650E3F48FD4`
- AAB SHA-256: `94E5D9CEE178A49AE0E5AB0374184FC6A0B395DBE533089D3D54ECAC547C3C60`
- release 서명과 빌드 메타데이터 `versionCode 217` / `versionName 1.0.202`를 확인했습니다. 준비 자산 213개와 번들 내부 파일 SHA-256이 모두 일치합니다.
- jarsigner `jar verified`/종료 코드 0. 자체 서명 체인·타임스탬프 없음 및 ZIP 엔트리 순서 관련 경고는 있으며 Play 업로드 검사는 아직 하지 않았습니다.
- Play에 이미 217 이상을 올렸다면 이 AAB를 올리지 말고 더 큰 versionCode로 다시 빌드해야 합니다.

## 216 이후 변경

- 관계 편집 화면을 모바일 세로 스크롤 카드 구조로 다시 배치했습니다. 캐릭터 선택 목록은 자체 스크롤 영역을 사용하고, 관계 유형·단계·과거 관계·순서·외부 공개·태그·동거 설정과 저장 버튼이 서로 겹치지 않습니다.
- “앞의 두 캐릭터 위치 바꾸기”를 없애고, 관계에 선택한 모든 캐릭터를 순서 목록에 표시합니다. 각 캐릭터의 위·아래 버튼으로 전체 표시 순서를 바꿀 수 있습니다.
- 부부의 법적 등록 여부를 “관계가 밖에서 다뤄지는 방식”에서 분리해 별도 체크 항목으로 만들었습니다. 법적 등록 여부와 외부 공개 방식은 각각 독립적으로 저장됩니다.
- 216에서 저장된 부부의 법적 등록 선택도 새 필드로 자동 이전하며, 다른 관계 유형에는 법적 등록 상태를 남기지 않습니다.
- 새 안내와 조작 문구를 한국어·영어·일본어로 함께 적용했습니다.

## 검증과 남은 확인

- 캐릭터 13명, 관계 구성원 3명인 384×854 화면에서 상단부터 저장 버튼까지 스크롤하며 모든 카드의 경계와 간격을 확인했습니다. 구성원 순서 목록, 외부 공개 선택, 법적 등록 체크, 동거 설정, 저장 영역이 겹치지 않습니다.
- 모든 선택 캐릭터 순서 변경, 부부 법적 등록 별도 저장, 기존 216 데이터 이전, 이전의 두 명 교환 버튼 제거를 자동 검사했습니다 (`scripts/check-relationship-editor-217.mjs`).
- JavaScript 구문 검사, 기존 소지품·우편함·관계 회귀 검사, 캐릭터 UI·선택 연속성·신고 오류 회귀 검사를 통과했습니다.
- 웹 빌드, Android/iOS 자산 준비, Android `clean assembleDebug bundleRelease`, iOS 프로젝트 정적 검사를 통과했습니다. Mac/iPhone/iPad 실기기 빌드·설치는 별도입니다.
- 전체 UI 정적 번역률: 영어 2086/2774(75.2%), 일본어 2085/2774(75.2%). 이번에 추가한 관계 편집 문구는 양쪽 모두 대응했으며, 이 수치는 동적 생활 로그 전체의 번역률은 아닙니다.
- Play Console 프로덕션 권한이 있어도 이 파일을 업로드하고 릴리스를 제출하기 전에는 사용자 앱이 바뀌지 않습니다. 먼저 debug APK로 화면과 저장을 확인한 뒤 AAB를 올리는 것을 권장합니다.

# 마을 공유 사전 제안 — 서버 기능 미구현

개인 사전과 마을 공유 사전을 분리한다. 기본 추천 권한은 방장/관리자만 공유본을 수정하고 멤버는 읽기·가져오기 가능하도록 하는 것이다. 사용자 권한 선호 답변은 아직 오지 않았다.

- 개인 항목을 선택해 공유본으로 보내기. 미리보기에서 종류·변경 수·남은 80개 한도를 확인한다.
- 마을은 공유 사전 ID와 사용 중인 버전을 참조한다. 공유본에 새 버전이 생겨도 마을에 자동 적용하지 않는다.
- 가져오기에서 내 내용 유지/공유 내용 사용을 직접 선택한다. 항목 ID와 버전으로 중복을 방지한다.
- 삭제되거나 권한이 사라져도 이미 선택한 버전이 갑자기 사라지지 않도록 보존 정책을 둔다.
- 같은 공유본을 여러 마을이 참조하면 중복 저장을 줄일 수 있지만 읽기·전송 비용까지 없어지는 것은 아니다.

261은 JSON 파일을 직접 다운로드·불러오는 단계까지 구현한다. 서버 참조·권한·마을별 연결·변경 미리보기는 별도 구현과 검증이 필요하다.

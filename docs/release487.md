# 내부 1.0.435 (487)

## 변경
- 식사 회복을 기본90초/+80에서 30초/+100으로 수정. 회복 중 자연 감소도 보정해 허기0에서30초 후100.
- 종료된 회복 시작 시각을 다음 식사에 재사용하지 않음. 장기 오프라인/재실행 뒤 새 회복 구간 설정.
- 자동 요리가 현재 식사/요리/욕구 활동을 끊지 않도록 보호.
- 식사 후 충분한 포만감이면 자유행동의 추가 식사/조리 후보 및 요리후식사 연속선택을 억제.
- 같은 마을의 최근 활성 행동·본인 최근 행동 종류를 읽어 덜 겹치는 자유행동을 우선 선택. 중복 독서 등 기존 자유행동도 분산. 사용자지시·공동활동·데이트·업무·욕구·수면은 강제로 분리하지 않음. 후보 제한 때문에 모든 행동의 중복을 완전히 금지하는 방식은 아님.
- 점심 외식 선택 기회25%→50%, 비연애 자유외출25%→50% 및 낮10시~20시로 시간 분산. 실제 건물/메뉴 선택은 기존 마을 및 카탈로그 사용. 등록 일정 우선권 유지.

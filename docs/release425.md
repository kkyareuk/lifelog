# 내부 425 · 1.0.373

개발 범위: dev, 공개 놀이 준비 중 유지. 새 게임은 낮 준비 → 회의/투표 결과 → 밤 침입 → 아침 발견으로 진행한다. 기존 판은 준비 규칙을 강제 이식하지 않는다.

- 낮 도구 확보, 잠자리 조사, 잠금 보강, 실제 침대 수 내 함께 자기. 준비 없는 야간 공격 금지. 시민도 같은 도구 사용 가능.
- 도구 소유자와 동맹은 비공개. 도구가 사라진 사실만 아침 공개. 동맹 제안 판당 한 번, 인간은 직접 수락/거절하며 정체를 공개하지 않는다.
- 사건 발생한 실제 집에 시신과 출입구 흔적 생성. 조사한 현장 기록과 불확실한 직감이 회의 근거가 된다. 낮 이동 기록은 새 판에서 제거.
- 목격자·관계에 따른 애도 반응, 동거인의 불확실한 야간 목격, 수면·그림자 연출. 그림자는 증거로 생성되지 않음.
- NPC 주 의견 즉시 시작, 반응 한 개씩 5초·반응 간 대기 축소. 지목된 사용자 반박/넘어가기, 변호에 감사, 투표자 내역 표시.
- 이동 연출 전 지도 카메라 유지. 신규 KO/EN/JA 문구 포함, 전체 번역률 미측정.

검증: 새 규칙 30판·기존 40판 완주, 준비/잠금/도구 소모·비공개 정보·침대 정원·회의/투표 회귀. 브라우저 검증과 배포 상태는 완료 후 기록.

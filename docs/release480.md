# 서랍마을 내부 1.0.428 (480)

## 변경
- 회사원·대리의 실무, 과장·차장·부장의 팀 관리, 이사 이상 임원의 경영 업무를 분리. 각각 12개의 제목/본문을 한국어·영어·일본어로 구성.
- 근무 일정 중 45분 단위로 업무가 이어지고 출근 준비·퇴근 정리는 별도로 표시. 캐릭터별 순서를 고정하여 새로고침으로 다시 뽑지 않으며 보통 9시간 근무일 내 반복 방지. 무한히 새로운 문장을 생성하는 방식은 아님.
- 실제 근무 요일/시간과 N잡 일정의 직업 ID 사용. 근무 중 직업을 바꿨을 때 과거 출근 기록이 없어 집에 남던 문제 수정. 기존 과거 기록은 덮어쓰지 않음. 현재 업무와 홈 직업 문구 연결.
- 근무 건물에 있는 직원은 사무 공간/회의실의 자리에 표시. 직원 목록에서 이름·직급·현재 업무 확인. 근무지에 없으면 부재 표시.
- 건물 내부에 집과 같은 목재 상단바·뒤로가기 및 건물 편집/방 정보/직원/편집모드. 건물 층수/방 구성/가구 편집과 기존 개인·멀티 저장 권한 유지.
- 건물 사진이 방의 벽지/바닥을 자동으로 덮지 않도록 수정. 건물 방의 사진 사용 옵션 제외. 원본 사진 데이터는 삭제하지 않음.
- 확대하지 않은 큰 마을도 한 손가락 이동 가능. 드래그 임계값을 넘기기 전에는 클릭을 유지하고, 방/가구 편집 핸들 및 두 손 확대와 분리.
- 일반 메뉴의 색/패딩 규칙이 건물 내부 상단바와 버튼을 덮던 범위 수정. 기존 아이콘/원화만 사용.

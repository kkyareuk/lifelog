# 서랍마을 1.0.257 · 개발판290

## 한국어
- 입주 신청을 관계 제안처럼 표시하던 문제를 수정했습니다.
- 입주·동거·일정·관계·캐릭터 그룹 제안을 각각 알맞은 문장으로 표시합니다.
- 제안 답변에 해당 캐릭터 이름을 표시하며, 거절 사유는 본문 한 문장에 함께 표시합니다. 별도 사유 칸은 제거했습니다.
- 관리자 본인 캐릭터의 입주는 방장 승인 없이 처리합니다. 일반 구성원의 입주 신청은 기존 승인 절차를 유지합니다.
- 앞서 전달한 개발판289의 이사 후보·3열 다중 선택·다른 멀티 이사 확인 기능을 포함합니다.

## English
- Fixed move-in applications incorrectly displayed as relationship proposals.
- Added distinct wording for move-in, shared-home, schedule, relationship and character-group proposals.
- Replies identify the relevant characters. Decline reasons appear in the message itself instead of a separate section.
- Administrators can move their own characters in without asking the group owner for approval. Regular members still require approval.
- Includes version289's move candidates, three-column multi-selection and cross-group confirmation.

# 집 착석·행동 UX 수정 (dev, 앱 1.0.329/378 유지)

- 직접 지정한 소파·의자 행동은 도착 후 이동 표시를 끝내고 가구 착석 렌더러를 사용한다.
- 소파 아이콘은 약 7% 축소하고 그림 세로 중심으로 정렬. 의자는 약 10% 확대. 일반 아이콘 고정 크기가 착석 크기를 덮지 않도록 기존 스타일 범위를 분리했다.
- 집 캐릭터 클릭은 현재 행동 카드, 카드의 명령 버튼은 할 일 창으로 이어진다. 캡처 단계의 문맥 메뉴가 가로채던 문제 수정.
- 소파에서 휴식·낮잠·독서·영상·음악·스킨십 선택. 낮잠도 수면 연출 적용.
- 음료 준비와 마시기 장소 분리, 준비/마시기 소품 애니메이션.
- 반려생물 경로와 절대 시간 애니메이션 위상을 유지해 재렌더마다 초기화하지 않는다. 현재 집 반려생물만 캐시에 보유.
- 하단 가구 선택 도구는 선택 가구 위로 배치.

검증: Chrome/WebKit 402×820에서 소파 낮잠 실행·착석 DOM·정보카드·할 일 창·하단 편집 도구 위치와 주요 탭 진입. 70개 생활 시뮬레이션 검사, 2인용 소파·식탁 의자 점유 검사, 반려생물 시간 유지 및 음료 준비 분류 검사 통과. 웹 빌드 성공. 실기기/멀티 서버/결제 검증 또는 앱 배포를 의미하지 않음.

추가 제보: 지저분한 공간 선호·정리 미루기·불성실한 생활, 튜토리얼 확장/상호작용 발견성, 반복 행동과 음식점 방문 조건은 후속 검토 대상으로 기록. 이번에 시뮬레이션 전반을 변경했다고 간주하지 않는다.

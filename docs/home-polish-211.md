# 집 화면 가독성 개선 · v1.0.196 / code 211

개발 브랜치 dev 전용. 운영 main, 운영 사이트 결제 설정, Google Play 배포는 변경하지 않음.

## 변경

- 전체설정 책의 중앙 종이 부분을 늘려 아래 아이콘과 페이지 넘김까지 받침. 원본 위·아래 테두리는 border-image 분할로 유지. 긴 외국어 대표 색상 제목 줄바꿈.
- 방/구성원 목록을 건물정보와 같은 목재 배경·크림색 판·사각 카드로 정리. 사진은 둥근 사각 프레임으로 제한하며 방 사진은 cover, 인물은 contain 사용.
- 깨진 이미지 URL이나 자동차 이모지를 이미지 주소로 사용하는 경우 대체 아이콘 표시.
- 방 편집의 사진·표면 샘플·입력 판과 체크박스 정리. 선택 글자와 배경 대비 수정.
- 가구창 분류 변경 시 높이 고정. 기존 좌/중/우 에셋으로 모든 테마 보기 버튼 구성. 검색창은 별도 팝오버로 열림.
- 방 이동/크기 조절 및 가구 드래그 중에만 격자 표시. 편집 완료와 가구 이름의 글자 채움색·줄바꿈 수정.
- 로그·요약의 중첩 패널 제거. 한 스크롤 영역 안에 종이 카드 표시, 긴 문장 줄바꿈, 시각·프로필·내용 분리.

## 반응과 공개

- 약함: 잠시 긴장하거나 주변을 살피고 자신의 속도를 유지함.
- 보통: 쉬고 싶다고 표현하거나 말수가 줄어듦.
- 강함: 버겁거나 잠시 멈추고 싶다고 표현함. 강제 이동이 아닌 현재 상황에 대한 로그 반응.
- 직접 입력은 문장을 인용하며 의미를 자동 추측하지 않음.
- 비밀 공유: 먼저 말하지 않음 / 믿는 상대에게만 / 가까워지면 비교적 쉽게.
- 이미 알고 있는 인물을 직접 지정할 수 있고, 실제로 들은 기록도 유지됨.
- 트리거는 현재 행동·장소·상황의 명시적 단서를 기준으로 연결되며, 사건을 반복 발생시키거나 매번 반응하지 않음.

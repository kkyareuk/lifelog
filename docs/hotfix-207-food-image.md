# 1.0.187.2 / code 207 음식 이미지 핫픽스

- Android에서 음식·음료 등 사전 항목의 `기기에서 업로드`가 저장 상태 때문에 열리지 않던 흐름을 분리했다.
- 업로드할 때마다 전용 파일 입력을 새로 만들고, 선택·취소·실패 뒤 작업 상태를 정리한다.
- 사진 선택기에서 앱으로 돌아올 때 이미 표시 중인 Data URL을 복원 완료로 오인해 편집 화면을 다시 그리지 않는다.
- 사진을 자른 뒤 사전 항목에 즉시 저장하고 현재 편집 화면의 미리보기를 갱신한다.
- 저장 실패 안내를 영어와 일본어에도 추가했다.

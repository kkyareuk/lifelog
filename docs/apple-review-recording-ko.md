# Apple 심사용 실제 기기 녹화 순서

Apple에서 받은 Guideline 2.1 요청에 대한 기능 시연 영상입니다. 실제 iPad/iPhone과 최신 정식 OS에서, 제출할 빌드와 같은 TestFlight 빌드를 사용합니다. 아래 시간은 추천 분량이며 Apple의 제한 시간이 아닙니다.

## 준비
- TestFlight에서 촬영할 앱 버전과 빌드 번호를 확인하고 기기 모델·OS 버전을 적습니다.
- 삭제해도 되는 촬영용 게임 계정, 직접 만든 캐릭터 이미지, 상대 역할의 테스트 계정과 멀티 그룹을 준비합니다.
- 알림을 끄고 iPad 홈 화면에서 화면 녹화를 시작합니다. 편집 효과와 음악은 필요 없습니다.
- 로그인 비밀번호와 인증 코드를 노출하지 않습니다. 주요 동작은 누른 후 결과가 읽히도록 잠시 멈춥니다.

## 촬영 순서 (약 6~10분 권장)
1. 홈 화면에서 앱 아이콘을 눌러 실행합니다. 첫 화면과 정상 로딩을 보여줍니다.
2. 처음 사용하는 촬영용 계정으로 앱 안에서 로그인/계정 생성 및 이름·프로필 설정을 보여줍니다. Apple 로그인 동작도 포함합니다. OS 계정을 새로 만드는 장면은 필요 없습니다.
3. 캐릭터 탭에서 캐릭터 생성, 성격·취미 설정, 저장 후 홈 화면을 보여줍니다.
4. 시키기에서 생활 행동 하나와 취미활동을 실행합니다. 상태·애니메이션·로그가 바뀌는 결과를 보여줍니다.
5. 집과 마을을 열고 방/가구 편집, 저장, 뒤로가기를 보여줍니다. 관계와 일정은 각각 한 번 설정하고 반영된 화면을 보여줍니다.
6. 멀티 그룹에 들어가 구성원과 공유 캐릭터를 보여줍니다. 테스트 상대에게 우편을 보내고 받은 편지를 여는 등 사용자 콘텐츠 흐름을 보여줍니다.
7. 멀티 구성원에서 테스트 상대의 멤버 신고를 열어 사유를 선택하고 추가 설명에 '심사용 테스트 신고'라고 적어 접수 결과까지 보여줍니다. 계정 차단도 별도로 실행하고 차단한 계정 관리에서 반영된 결과를 보여줍니다.
8. 상점에서 유료 상품 내용/가격을 보여주고 Apple 구매 창, 테스트 구매 완료, 실제 혜택 반영을 보여줍니다. 복원 가능한 상품이면 구매 복원도 보여줍니다. TestFlight 구매는 샌드박스입니다.
9. 마지막에 설정에서 촬영용 게임 계정의 계정 삭제를 실행합니다. 확인과 필요한 재인증을 거쳐 로그아웃/삭제 완료 결과를 보여줍니다. '계정 초기화'와 '계정 삭제'는 다른 기능입니다.

실제 오류가 보이면 해당 장면을 성공한 것처럼 편집하지 않고 수정 후 다시 촬영합니다. 본계정/실사용 캐릭터를 삭제하지 않습니다.

## 제출
영상은 App Store 홍보용 앱 미리보기가 아니라 App Review 답변의 첨부/접근 가능한 링크로 제공합니다. App Review Information의 Notes에도 영상 링크, 촬영 기기·OS·앱 버전·빌드 번호를 적습니다. Apple이 요구한 앱 목적, 사용법/심사 계정, 외부 서비스, 지역 차이, 콘텐츠 권리, 인앱 구매 설명도 별도로 필요합니다.

서랍마을 1.0.215.9 업데이트 (code 259)

이번 긴급 업데이트에서 변경된 주요 내용을 안내드립니다.

🔧 개선 사항
• 캐릭터가 많은 마을에서 생활·관계 계산과 연속 자동 저장의 부담을 줄였습니다.
• 저장 공간이 부족할 때 저장 데이터를 더 작게 보관하고, 사전 사진 보관을 완료한 뒤 저장을 다시 시도합니다.

🐛 오류 수정
• 사전 저장에 실패했을 때 뒤로 가기도 막히던 문제를 수정했습니다. 저장할 수 없는 경우 입력을 임시로 유지한 채 목록으로 돌아갈 수 있습니다. 앱 종료 전 다시 저장해 주세요.
• 종료된 일정이 현재 행동으로 계속 선택되는 경우를 막았습니다.
• 외출 일정 종료 후 귀가 장면이 함께하는 일정으로 계속 취급되지 않도록 수정했습니다.

이번 파일은 긴급 수정판입니다. 멀티 전체 기능 확장·새 사전 항목 등 개발 중인 기능은 포함하지 않습니다.

English
• Reduced repeated life/relationship calculations and consecutive automatic saves in large towns.
• Improved storage-full recovery and retry saving dictionary edits after photos are stored.
• You can return to the dictionary list with a temporary draft if saving fails. Save again before closing the app.
• Prevented expired schedules from remaining the current activity and separated return-home scenes from shared activities.

日本語
• 人物が多い村で生活・関係の重複計算と連続自動保存の負荷を軽減しました。
• 容量不足時の保存を改善し、辞典の写真の保管後に保存を再試行します。
• 保存に失敗しても入力を一時的に保持して辞典一覧に戻れます。アプリを閉じる前に再保存してください。
• 終了した予定が現在の行動として残らないようにし、帰宅場面を共同活動から分離しました。

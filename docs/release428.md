## 적용 내용

- 사진 정리 화면의 수를 ‘누적 업로드 파일 (교체 전 사진 포함)’로 표시. 현재 기록에서 쓰지 않는 파일은 동기화 이미지 한도 계산에서 제외한다. 실제 저장소 파일은 삭제하지 않았다.
- 깊거나 큰 core/인물/날짜 기록을 각각 압축하여 저장. 깊은 항목 하나 때문에 전체 저장을 단일 호환 문서로 합치던 경로를 제거했다. 호환 저장 크기 오류를 Firebase 권한 문제처럼 안내하던 문구를 수정했다.
- 행동 의미에 맞는 가구만 선택하고 급한 욕구 행동이 시작되면 이전 가구 지정을 해제. 실제 선택된 방과 위치 문구를 맞췄다.
- 집 편집에서 UI·가구·이름 숨김/표시, 편집 취소. 취소하면 편집 시작 시 방·가구·거주 설정으로 복구하며, 편집 중 임시 배치는 계정 동기화에서 제외한다.
- 방 편집에서 같은 집 안의 프리셋 저장/적용(최대 20개). 복제한 가구 ID는 새로 만들고 지정 인물은 비운다.
- 자아 만들기 질문 대기시간을 계정·공간·캐릭터별로 분리.
- 밀색·백금발 등 머리색, 헤이즐·올리브 등 눈색 추가. 색상 선택과 직접 이름 입력 지원.
- 광장 하단 아이콘을 분수로 단순화하고 준비 중 안내의 대비 개선.
- 마피아 ‘오늘의 무대’ 수동 선택 제거, 선택 마을의 장소 자동 구성. 방장이 마피아 수(인원에 따라 1~3), 이동/실내 행동(15~120초), 회의(60~600초)를 설정한다.
- 마피아 종료 후 날짜별 이동·행동·목격·회의·투표 기록 표시. 실제 밤 공격과 성공/실패를 기록하며, 위조 정보와 주관적 슬픔 판단은 확정 목격에서 제외한다. 진행 중에는 전체 기록을 공개하지 않는다.

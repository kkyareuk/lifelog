# 우편·캐릭터 공유 문의 답변 / 1.0.333 (385)

## 캐릭터 소유권

안녕하세요. 현재 멀티 마을에서 기존 캐릭터의 소유권을 다른 계정으로 직접 넘기는 기능은 지원하지 않습니다.

대신 ‘프로필 내보내기 → 공유 코드 만들기’로 코드를 전달하면, 상대방이 ‘공유 코드로 불러오기’에서 사진과 설정을 자신의 캐릭터로 복사할 수 있습니다. 받는 계정에는 빈 캐릭터 슬롯 1개가 필요합니다.

이 방식은 별도의 캐릭터를 만드는 기능이므로 기존 멀티 캐릭터의 소유권이나 관계·생활 기록을 그대로 이전하지는 않습니다. 참고 부탁드립니다!

## 실수로 보낸 우편 기록 삭제

안녕하세요. 우편함의 ‘보낸우편 → 선택 삭제’에서 삭제할 편지를 체크한 뒤 ‘선택 삭제’를 누르면 본인의 보낸 기록에서 지울 수 있습니다.

다만 이는 내 기록을 지우는 기능으로, 상대방에게 이미 도착한 편지를 회수하거나 전달된 선물을 취소하는 기능은 아닙니다. 이용에 참고 부탁드립니다!

## 선물 카테고리 누락

안녕하세요. 의도적으로 제외한 것이 아니라, 우편으로 선물을 보내는 화면에서 ‘아이돌·밴드’와 ‘취미’ 물품이 누락된 오류를 확인했습니다. 불편을 드려 죄송합니다.

해당 물품도 다시 선택하고 전달할 수 있도록 수정하여 내부 테스트에 반영했으며, 확인 후 다음 업데이트에 반영하겠습니다. 자세히 알려주셔서 감사합니다!

## 우편 선택·저장 오류 답변

안녕하세요. 보내주신 진단에는 앱의 저장 영역 한도 오류가 반복되어 기록돼 있습니다. 휴대폰 전체 용량이 부족하다는 뜻으로 단정할 수는 없습니다. 저장 실패 때 우편 선택과 화면 표시도 지연될 수 있는 부분을 수정하고, 큰 게임 저장본을 별도의 기기 저장소에 보관하도록 개선했습니다. 내부 테스트 후 다음 업데이트에 반영하겠습니다. 기존 데이터를 보호하기 위해 앱 데이터 삭제나 재설치는 하지 말아 주세요.

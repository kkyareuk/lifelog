# Release 348 / 1.0.315

Development release after delivered 347. Main/live app is unchanged.

- Retain stored user mail/proposals and official notices without age expiry. Keep old read markers. Bounded 50-document cursor pages per mailbox stream; load older mail explicitly.
- Select ordinary letters for deletion from the viewer's mailbox only. Server validates participants, denies notices, and atomically marks only the requesting viewer. Local contact letters use account-scoped hiding.
- Announcements bypass existing sender blocks in sending, server reads and client filtering. No block action in notice reader; server refuses direct notice block requests. Ordinary mail blocking remains active. Non-staff letters to staff do not become unblockable announcements.
- Notice publishing remains explicit and no push/email is generated by the notice administration site.
- Complete feature reference, tutorial ordering and Claude handoff prompt in Korean DOCX/Markdown; current versus deferred features are distinguished.

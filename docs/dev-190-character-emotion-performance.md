# dev 1.0.177 (190) — 캐릭터 감정 성향·편집 성능

## 사용자 변경 사항

- 캐릭터 성격 8페이지와 기존 상세 성격 페이지 사이에 `감정 성향` 9페이지를 추가했다.
- 감정 기본값, 변화 폭, 지속 시간, 좋은 일·스트레스 반응, 회복 방식을 캐릭터별로 설정할 수 있다.
- 낙천적인 캐릭터는 평범한 상황에서 무작위로 `무덤덤함`이 되지 않으며, 부정적 사건은 성격에 맞는 긴장·걱정·가라앉음 등으로 반응한다.
- 캐릭터 전체설정에서 현재 페이지에 필요하지 않은 모바일 허브·데스크톱 폼·대화상자를 동시에 만들지 않도록 렌더 구조를 분리했다.
- 캐릭터 책의 입력·선택·추가 버튼을 3페이지와 같은 눌리는 입체 버튼 계열로 통일했다.
- 건물 드레스코드는 별도 선택창에서 색상·재질·분위기를 각 3열로 고를 수 있게 바꿨다.
- 한국어로 남아 있던 생성형 생활 로그는 영어·일본어 UI에서 행동 의미를 유지하는 번역 폴백을 거친다.

## 번역

- 감정 성향 화면과 선택지는 한국어·영어·일본어를 함께 추가했다.
- 생활 로그 번역 폴백은 영어·일본어 모두 적용된다.
- 전체 정적 UI 사전 기준 진행률은 영어 73.4%, 일본어 73.3%다.

# 서랍마을 iOS 내부 테스트 1.0.198 (5)

태블릿 화면 개선을 포함한 로컬 플레이 준비판입니다. 정식 출시 버전이 아닙니다. 비교 기준은 이전 내부 TestFlight 1.0.198 (4)입니다.

## 한국어

- 세로로 돌렸을 때 마을 화면과 버튼 배치가 깨지는 문제를 수정했어요.
- 집·방 정보의 검색창, 제목, 사진 크기를 조정하고 닫힌 편집창과 구성원 목록이 노출되지 않도록 수정했어요.
- 집 옆 사진의 비율과 태블릿 지도·캐릭터·메뉴 간격을 정리했어요.
- 캐릭터가 한 명인 관계 화면에 뒤로가기와 캐릭터 추가 안내를 제공해요.
- 가로·세로 회전, 방 편집 뒤로가기, 저장 후 재실행을 확인해 주세요.

캐릭터 만들기, 집·마을 화면, 사진 선택, 저장 후 앱 재실행, 발소리와 알림을 확인해 주세요.
로그인, 클라우드 동기화, 구매는 아직 사용할 수 없습니다. 기존 데이터가 있는 기기를 사용할 때는 먼저 백업해 주세요.
시작 아이콘과 일부 iOS 권한 문구는 임시 상태입니다. 화면 잘림·버벅임·소리 문제를 발견하면 사용한 기기와 발생 화면을 알려 주세요.

## English

This is an updated local-play iOS preview, not a production release.
Fixed the town layout when rotating a tablet to portrait. Resized house/room headers, search and photos; hidden editor/member panels no longer leak onto the house screen. Preserved the house image proportions and improved spacing between the tablet map, character and menus. The relationship screen with one character now includes a back button and guidance to add another character. Please check rotation and returning from room editing.
Please test character creation, house and town screens, photo selection, saving and reopening the app, footsteps, and notifications.
Sign-in, cloud sync, and purchases are not available yet. Back up any existing data before testing.
The launch icon and some iOS permission messages are provisional. Please report your device and the screen where clipping, stuttering, or audio problems occur.

# 서랍마을 1.0.174 / 187 개발 기록

## 캐릭터 옷장

- 별도의 상태별 아이콘·LD 등록 버튼은 화면에서 제거했다.
- 캐릭터 전체 설정 11페이지의 옷장에서 SD 아이콘과 LD를 함께 등록한다.
- 옷마다 상황, 기분, 따뜻함, 격식, 편안함, 필수 유니폼 여부를 정할 수 있다.
- 홈 화면은 현재 행동과 기분에 맞는 보유 옷의 그림을 고르고, 맞는 옷 그림이 없을 때만 기본 아이콘·LD를 사용한다.

## 공동 행동과 로그

- 일반 공동 행동은 두 캐릭터의 실제 마을·건물·집·방이 같은 경우에만 확정한다.
- 하나의 상호작용 ID와 참여 순서를 양쪽 로그에 공유하되 제목과 설명은 각 캐릭터 시점으로 작성한다.
- 과거 엔진의 막연한 `미뤄 둔 약속의 조건` 문장은 출발 시간, 식사 예산, 취소 연락 중 하나의 구체적인 갈등과 합의로 정리한다.
- 긴 반복 설명은 줄이고 마을과 건물의 분위기는 성격에 따른 구체적인 반응으로 표현한다.

## 기분과 화면 효과

- 기분은 현재 사건, 피로, 장소 분위기, 마을·건물 평판, 성격, 시각별 생활 리듬을 함께 반영한다.
- 평온함 외에 기분 좋음, 들뜸, 지루함, 긴장함, 화남, 슬픔, 피곤함이 더 자주 구분된다.
- 장면 효과는 실제 기후가 아니라 현재 사건과 캐릭터의 기분을 시각화한다. 기후 자체는 별도의 확장 기능으로 유지한다.

## 마을과 건물

- 평판은 좋은지 나쁜지, 인지도는 얼마나 널리 알려졌는지를 나타내는 서로 다른 값으로 분리했다.
- 사용자 원본 시트에서 카페, 병원, 피아노 음악당, 공원, 빨간 지붕 집과 각 불빛 레이어를 동일한 경계로 다시 추출했다.

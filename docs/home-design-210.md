# 집 UI · v1.0.195 (code 210)

개발 브랜치: dev. 운영 main·웹사이트·Google Play 배포는 변경하지 않음.

## 변경

- 구성원 메뉴에서 구성원·반려생물·차를 한 화면에 표시. 각 구역의 추가와 개별 편집을 연결하고, 편집창의 뒤로가기는 구성원 화면으로 복귀.
- 방/구성원/차 편집에 같은 사진 프레임·나무 배경·뒤로가기 레이아웃을 사용. 제공 SVG에서 배경을 추출하고 412×917 좌표 비율을 기준으로 사진, 표면 샘플 각도, 입력 영역을 배치.
- 방 제목 색·크기·층 선택은 방 편집에서 제거하되 기존 값은 보존. 청결도·주인·출입 목록·사진 사용·세부 용도 저장.
- 하단 로그·요약 버튼의 공통 절대 위치 충돌을 수정. 메뉴 이름은 구성원.
- 집 정보 사진과 필드는 마을 집 편집과 동일한 home 상태 및 외관 자산 사용. 다른 화면용 복제 정보는 만들지 않음.
- 이번에 추가/수정한 정적 문구의 영어·일본어 번역 완료. 전체 기존 UI/생활 로그 번역률은 미측정.

- check-home-editor-209: 가구 격자·방향 저장·침대 선택 범위·기존 성능 개선 회귀.
- check-home-surfaces, check-navigation-event-boundary (9건), check-home-life-simulation (70건) 통과.
- Android 웹 준비·모듈 의존성·패키징 자산 검사 통과. assembleDebug / bundleRelease 성공.

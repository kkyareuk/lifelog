# 1.0.477 / 529 — 감정·상호작용 이미지 (개발판)

- 캐릭터 전체 설정 표지의 ‘감정·상황별 이미지’에서 SD/LD를 각각 등록한다.
- 기쁨, 슬픔, 화남, 부끄러움·설렘, 긴장, 피곤함 및 대화, 포옹, 선물, 다툼을 지원한다.
- 수면 우선. 그 외 현재 행동 → 감정 → 일상으로 상태를 선택한다. 선택한 상태의 칸이 비어 있으면 유저가 등록한 기본 SD/LD(없으면 프로필 사진)로 표시한다. 다른 상태나 옷장 이미지로 대체하지 않는다.
- GIF는 1.5MB 이하 원본을 그대로 보존한다. 정지 이미지의 기존 자르기 기능은 유지한다. 큰 GIF는 안내 후 거절하며 클라우드에서도 정지 이미지로 변환하지 않는다.
- Chrome/WebKit에서 3개 언어 설정 화면과 GIF 업로드 원본 바이트 보존 검사 통과. 이미지 우선순위·기본 이미지 대체·거절된 접촉·수면·기존 옷장 검사 통과.
- 새 문구 한국어/영어/일본어 100%. 기존 전체 번역률 미측정.
- 개발판 대상이며 프로덕션 승격은 포함하지 않는다.

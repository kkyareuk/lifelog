• 집 화면에서 반복되는 계산을 줄이고 화면 표시 뒤에 처리할 작업을 분리했어요.
• 반복 화면 전환 시 불필요한 스크롤 복원과 이미지 처리를 줄였어요.
• 새 질문과 답변에 영어·일본어 번역을 추가했어요.

• 질문이 실제로 바꾸는 성향의 잠금 여부를 확인하도록 개선했어요.

# 1.0.350 (402) — 광장 활동 UI · 짧은 마피아 턴 · 멀티 산책 연속성

기준: dev4032ea9 / Android400. 사용자 SVG 3종을 시각 배치 참고로 사용. 원본 SVG의 대용량 임베디드 이미지를 통째로 탑재하지 않고 기존 나무·마을·버튼 에셋과 반응형 DOM으로 구성.

## 변경
- 홈의 광장 명칭은 유지하고 내부를 함께하는 활동으로 구성. 멀티별/전체 게임 카드 목록, 정렬, 실제 참여 인원, 방장 사진, 멀티 초대 코드 참여.
- 체크무늬 설정 화면: 게임명/정원/내 참가 캐릭터/게임 장소, 소유자가 허용한 NPC로 충원 후 시작. 기존 자동 참가 허용 설정도 유지.
- 새 게임 live 모드: 낮 행동 6회, 1회 60초에 장소·행동 하나 제출. 기존 밤 처리는 낮 행동 뒤 진행. 첫 진술·추리2회·투표는 각45초. 서버가 마감 기준으로 진행하며 미제출자는 자동 행동.
- 이미 만들어진 async 게임은 6/12/24시간 유지. 예전 클라이언트의 6칸 제출은 live 게임에서 첫 행동만 검증·적용하여 입력 오류 방지.
- 지도 위 장소 선택과 행동 선택. 이동 가능한 이웃 장소만 선택하며 타 장소 선택 시 이동 동작만 허용. 위조 위치나 마피아 전용 동작은 서버에서도 검증.
- 회의 내용은 밝은 종이 패널로 분리. 라이브 행동 폼은 화면 처음에, 부가 정보/참가자/기록은 펼침 영역에 배치.
- 산책 애니메이션의 지연값을 목록 순서 대신 절대 시각과 캐릭터/장면 시드로 계산. 멀티 갱신 때 DOM이 다시 만들어져도 같은 경로의 애니메이션 위치 유지.

기준 dev f6fa66b2. Play 최신 내부508 제공 확인 후509 사용. 기능 변경은 codex/furniture509 → dev. 구형 main의 운영 사이트 연결은 유지하고 릴리스 문서만 반영한다.

## 변경
- 새로 그린 무늬 없는 카운터. 길이 슬라이더를 네 가장자리 드래그로 교체. 아홉 조각으로 좌우 테두리와 위 테두리·하단 나무를 보존하며 가운데 상판을 늘린다. 반대쪽 가장자리를 고정하고 가로·세로 길이를 저장한다.
- 책상 앞·옆·뒤 그림 및 가림 레이어. 사용 중인 인물과 앞쪽 조각의 겹침을 처리한다.
- 욕조 기본 그림과 사용 중 욕조 뒤 → 물 뒤 → 인물 → 물 앞 → 욕조 앞 순서. 함께 사용하는 두 인물도 별도 자리로 표시한다.
- 방 크기 드래그 중 가구의 기준 격자 갱신 누락 수정. 저장 렌더와 같은 계산을 사용한다.
- 씻기 거품8개의 위치·크기·주기·지연을 인물별로 분산. 재렌더 시 갑자기 다시 배치하지 않고 동작 줄이기/끄기를 따른다.
- 바닥과 벽지 사진을 별도로 첨부·저장. 바닥 사진은 반복 바닥으로 표시하며 벽을 보존한다. 기존 방 전체 그림 모드는 유지한다. 개인 집·공유 집·건물 편집 경로 연결.
- 사용자 원본 체크 타일을 바닥과 벽지 목록에 추가. 가구 원본 그림은 crop-furniture509.py로 원본 픽셀만 추출했다.

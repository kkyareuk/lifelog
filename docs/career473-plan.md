# 직업·재산 / 급여 시스템 473

기본 직업 23종과 95개 직급. 게임 밸런스용 금액이며 실제 임금 통계가 아니다. 기본 외식 1끼=10,000원이다.

캐릭터 메뉴에서는 개인 직업·직급·부서/소속·세부 분야/병과·표시 직업명·지급 주기와 재산을 설정한다. 서랍에서는 현재 개인/멀티 세계의 직업과 화폐를 관리한다. 멀티의 새 직업 생성 허용은 방장/관리자가 그룹 규칙에서 설정하며 기존 직업 수정·모집 종료는 생성자 또는 관리자 권한으로 처리한다.

직업별 월 정산일을 1~31일로 설정한다. 없는 날짜는 말일. 캐릭터별 일급/주급/월급은 같은 월 환산액을 사용하며 기본 월급의 지급액은 1,000원 단위다. 일급은 매일 자정, 주급은 해당 급여 기간 시작부터 7일 간격과 월 정산일, 월급은 월 정산일에 지급한다. 남은 기간과 단위 차액은 월 정산일에 함께 정산한다. 중도 등록/직급 변경은 기간 비례이고 중복 지급을 방지한다. 사용자 지정 금액은 정수 기본 통화로 정산한다.

처음 캐릭터 직업 메뉴에서 서류를 제출한 시점부터 새 급여가 발생한다. 기존 지갑 잔액은 유지하며 과거 재직 기간을 소급 지급하지 않는다. 월급 수정은 다음 정산 처리에서 새 기준으로 전환하며 지난 기간을 새 직급 급여로 다시 계산하지 않는다. 업무 이름/설명은 실제 근무 장면에 사용한다.

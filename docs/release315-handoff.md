## 변경
방 주인·구성원 자는 방의 기존 양방향 연결을 유지하고, 방 권한 변경을 생활 캐시 서명/무효화에 포함. 눈을 붙이는 낮잠도 수면으로 판별하여 지정 방·출입 권한과 혼자 쉬기 보호 적용. 구성원 탭의 다른 곳에서 자기 기본값false, 드물게5%/가끔15%/자주35%. 허용된 living/rest 방만 사용하며 같은 밤 자정 전후 장소 유지. 기온 연동은 포함하지 않음.

1인 침대가 이미 차 있을 때 이전 침대 점유를 그대로 유지하던 경로 수정. 빈 침대가 없으면 같은 방의 별도 자리로 배치하며 침대 중복 사용하지 않음. 커플 침대 기존2인 수용 유지.

상대 ID가 있는 자동 집 대면 장면은 같은 방 여부 확인. 다른 방이면1분 이동 장면 뒤 원문 대면 장면 재개. 권한 없음/상대 수면/다른 집은 자기 자리 휴식으로 대체. 프로필 관계 장면에 상대 ID 연결. 원격 연락/예약 일정/명시적 시키기는 기존 전용 경로 유지.

태블릿 가로에서 오른쪽 작은 세로 아이콘을 아래쪽 기존3버튼과 글자로 복구. 폰에서는 글자를 숨기고 기존위치 유지. 입원/병원숙박은 직업팩DLC 검토 보류이며 구현하지 않음.

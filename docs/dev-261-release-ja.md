引き出し村 1.0.232 開発版アップデート — versionCode 261

dev機能確認用です。運用mainは1.0.215.9 / 259のままです。Google Playにはアップロードしていません。

新機能
- キャラクター名の横のプロフィール出力から、設定をJSONで保存・読み込みできます。読み込みは空き枠に新しいキャラクターを作成します。個別設定には写真・生活ログ・関係は含みません。
- 同じ画面で設定全体のバックアップを保存できます。全体バックアップには関係と生活記録を含み、写真は端末管理です。復元は既存の設定画面のバックアップ読み込みを使います。
- 辞典に花・その他の物品を追加しました。人形なども登録できます。
- 辞典全体のファイル保存・読み込みに対応しました。同じ項目の再読み込みは更新になり、種類ごとの追加上限は80件です。既存の超過データは削除しません。
- ソーダ・モヒート・ノンアルコールモヒート・エード・スムージー、ローファー・ビジネスシューズ・オックスフォード・ダービー・モンクストラップ・下駄・一本歯下駄・草履・伝統的な履物を追加しました。

改善・修正
- 寝室の持ち主と住人の寝る部屋の設定を相互に反映します。
- 飲み物の辛さをなくし、甘さ・酸味・炭酸・カフェイン・アルコール・温度に変更しました。
- 提供されたSVG素材に基づくマルチ一覧、3列カード、検索・自分のグループ絞り込み・並べ替え・村の空き枠付き追加画面を導入しました。
- タイプ選択のキーワード文字を小さくし、折り返しに対応しました。提供されたサムネイルをWebビルドに反映しました。公開サイトへの配信は別途です。
- 全体設定4ページの総評を選択直後に反映し、再起動後も維持するdev修正と、辞典の保存失敗復旧・予定終了・多人数処理の既存修正を含みます。

未収録: サーバー共有辞典・インテリア、マルチの生活全機能・関係提案通知、新しい健康・複合家族設定。ファイル交換は手動です。BGMは制作していません。

検証: モバイル画面、JSON保存と設定の往復、寝室の連携、80件制限、マルチ操作、保存容量エラーの復旧・予定終了、Androidビルド。実機の長時間発熱とPlay配信は未検証・未実施です。

## 수정
- 저장: 저장 공간이 허용되면 이전 IndexedDB 참조를 압축 원문으로 되돌림. 복구본은 참조 별칭 대신 독립된 원문을 우선 보관. 시작할 때 복구 원문을 다시 같은 데이터베이스로 옮기지 않음. 공간 부족이면 기존 복구본 보존. IndexedDB 쓰기 strict durability, 정리 실패는 이미 완료된 저장을 실패로 오인하지 않음.
- 교류: 공동 행동 확정 시 상대의 급한 개인 욕구 행동도 확인. 상대가 식사 등으로 전환되는데 한쪽만 대화가 남는 재현 해결.
- 수면: 남아 있는 낮잠·귀환 수면 장면이 시간표 밖에서 선택되지 않도록 실제 현재 장면을 보정. 직접 지시/등록 일정은 유지.
- 재산: 지갑 설정에 캐릭터별 금액 적용 추가. 다른 캐릭터나 세계관 환산값을 바꾸지 않음. 공유 지갑은 공유 해제 후 수정, 서버 소유권 검사 유지. 수입·지출에 따른 정상 변동은 유지.

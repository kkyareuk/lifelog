# v1.0.184-dev (197) — 2인 침대와 건물 원화

## 2인 침대

- 바탕, 이불, 발판을 동일한 640×684 캔버스의 세 레이어로 정렬했다.
- 편집 이동·확대·회전은 세 레이어가 같은 가구 좌표를 사용한다.
- 일반 이동 중에는 캐릭터가 침대 전체 앞에 보인다.
- 침대 위 행동 중에는 발판만 캐릭터 앞에 놓인다.
- 잠든 상태에서는 이불과 발판이 캐릭터 앞에 놓여 이불 안에 들어간다.
- 두 사용자의 좌우 배치 선호를 먼저 적용하고, 선호가 같으면 장면 시드 기반의 안정적인 무작위로 자리를 나눈다.
- 머리 위치는 양쪽 베개 기준 오프셋을 사용하며 침대 회전과 함께 회전한다.

## 건물 원화와 조명

- 카페, 병원, 피아노 공연장, 웨딩드레스 부티크, 원형 경기장, 도심 오피스, 학사모 학교, 여행가방 호텔, 시계탑 학교, 책더미 도서관, 옥상 정원 건물, 붉은 지붕 집, 공원을 건물 도감과 오프라인 자산에 등록했다.
- 카페, 병원, 피아노 공연장, 도심 오피스, 붉은 지붕 집, 공원은 별도 조명 레이어를 원화와 같은 좌표로 적용한다.
- 원본 PNG의 바깥과 연결된 투명 영역만 배경으로 취급한다. 검은 윤곽선으로 닫힌 투명 영역은 불투명 흰색으로 복원해 흰 건물 면이 사라지지 않게 했다.

## 번역

- 이번에 추가된 건물 이름과 원화·조명 안내 문구는 영어와 일본어를 모두 제공한다.
- 정적 UI 집계: 영어 2071/2810(73.7%), 일본어 2070/2810(73.7%). 생활 로그와 사용자 작성 텍스트는 이 집계에 포함하지 않는다.

- 기존 `test:town-grid`는 26/30 통과. 실패한 네 항목이 이번 작업 전 `dev` 소스에도 없는 과거 정확 문자열을 검사하는 것을 확인했으며 이번 변경 범위와 무관하다.

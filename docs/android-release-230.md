# Android 개발 빌드 1.0.213 (code 230)

- 브랜치: `dev`
- 빌드 표식: `20260906dev230`
- 상태: APK/AAB 생성 및 로컬 검증 완료. Google Play에는 업로드하지 않음.

## 변경 사항

- 잠든 캐릭터를 깨운 뒤 씻기, 식사, 독서, 휴식, 운동 등 원하는 활동을 바로 지시할 수 있게 했습니다.
- 함께 활동하는 캐릭터의 관계가 실제 상호작용을 바탕으로 자동 생성·발전하도록 했습니다. 사용자가 직접 편집한 관계 단계와 적대·라이벌 관계는 자동으로 덮어쓰지 않습니다.
- Android 태블릿 가로 화면의 캐릭터 전체설정을 양면 책으로 크게 표시하고, 세로 화면에서는 캐릭터 목록을 감춰 책과 버튼이 화면을 충분히 사용하도록 조정했습니다.
- 태블릿 가로 화면의 사전과 공식 관계 목록이 과도하게 좁아지지 않도록 콘텐츠 폭과 카드 열 수를 화면에 맞게 확장했습니다.
- 태블릿 가로 마을에서 캐릭터 아이콘 뒤의 흰 사각형과 장식 배치 외곽선을 제거하고 관찰 화면의 배치를 정돈했습니다.
- Android 시스템 내비게이션 바와 콘텐츠가 겹치지 않도록 WebView에 실제 시스템 안전 영역을 반영했습니다.
- 새 활동 선택 기능의 한국어·영어·일본어 문구를 함께 반영했습니다.

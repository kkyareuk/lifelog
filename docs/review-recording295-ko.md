# iOS 1.0.262 (19) 심사 녹화 순서

최신 정식 iPadOS의 실제 iPad에서 TestFlight 버전을 확인하고 녹화합니다. Apple 웹사이트가 아니라 앱 실행 화면을 녹화합니다. 19가 TestFlight에 표시되기 전에는 최신 기능 녹화를 시작하지 않습니다.

1. 홈 화면에서 녹화를 시작하고 서랍마을을 실행합니다.
2. 테스트용 계정으로 로그인하고 프로필 설정을 보여줍니다.
3. 캐릭터 생성·편집, 집과 마을, 활동 선택을 실제로 실행합니다.
4. 테스트 계정 두 개가 참여한 멀티에서 구성원 및 받은 우편의 신고·계정 차단 메뉴를 엽니다.
5. 실제 이용자가 아닌 별도 테스트 계정의 테스트 콘텐츠를 신고합니다. 추가 설명에 심사 녹화용 테스트임을 적고 접수 결과를 보여줍니다.
6. 계정을 차단하고 해당 계정의 캐릭터가 숨겨지는지 확인합니다. 상대 계정에서도 우편·제안·직접 상호작용이 거절되는지 확인합니다.
7. 설정의 차단한 계정 관리에서 해제를 보여줍니다.
8. 상점 상품과 Apple의 테스트 구매 흐름을 보여줍니다.
9. 마지막에 폐기 가능한 테스트 계정으로 계정 삭제를 보여줍니다. 운영용 계정과 실제 이용자 계정은 삭제하지 않습니다.

영상과 실제 테스트 결과를 확인한 후 App Review 답변·Notes와 함께 제출합니다. 빌드 업로드 성공은 Apple 심사 승인이나 출시 완료를 뜻하지 않습니다.

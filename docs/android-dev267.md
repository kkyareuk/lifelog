이번에 바뀐 화면

- 멀티 관계창을 개인 마을과 같은 캐릭터 선택/시선 설정 화면으로 바꿨습니다. 화면 상단의 별도 그룹 탭을 제거하고 기존 그룹 버튼에서 이동합니다.

- 멀티 마을의 마을 정보·건물 정보·편집모드를 다시 연결했습니다. 소유자/관리자/운영자는 건물 추가·삭제·이름/유형/모양/크기/불빛·판매 목록을 공유 저장할 수 있습니다.
- 지도에서 건물·공유된 집·장식을 끌어 옮기고 크기/좌우 반전/앞뒤 순서를 바꿉니다. 배치 변경의 되돌리기/다시 실행도 공유 저장합니다.
- 멀티 목록의 초대 코드와 참여하기, 전체/내가 만든 그룹, 검색을 구분해 배치했습니다.

검증

- 기존 관계창/시선 저장/제안/거절 사유, 한국어·영어·일본어 가로 넘침 검사 통과.

- 서버 편집 권한·동시 편집 충돌·집과 장식 저장·시선 항목 보존 검사 통과.

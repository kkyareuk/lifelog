- 설정 첫 화면의 익명 문의. 메일 앱을 여는 유형별 메뉴 제거.
- 설정 > 도움말 > 따라하며 배우기: 캐릭터 만들기 경로, 행동 확인, 행동 메뉴, 질문, 설정 안내. 사용자가 진행하며 건너뛰기 확인과 재시작 지원. 최초 실행 자동 온보딩 전체를 대체한 것은 아니다.
- 의자 착석 크기를 작은 가구 폭에 종속시키지 않고 2인 침대와 같은 46–60px 기준(기본52px)으로 조정. 소파와 서 있는 캐릭터는 이번 변경 대상 아님.
- 라이벌 배경에 정치·학업/연구·직업/사업·예술/기술 선택 추가. 기존 옵션 ID와 기존 관계 보존.

# 개발판 1.0.168 / 181

작업 브랜치: dev. 운영 main 및 Google Play 업로드는 포함하지 않음.

## 변경

- 로그인 UID별로 기기 저장, 복구본, 초기화, UI 계정 정보를 분리. 소유자를 알 수 없는 구버전 저장은 손님 데이터로 별도 보존하고 자동 합치지 않음.
- 계정 전환마다 해당 계정 데이터를 불러오며, 전환 전에 시작된 저장·불러오기·이미지 복원의 늦은 응답을 새 계정에 적용하지 않음.
- 이미 과거에 섞여 클라우드에 저장된 캐릭터는 소유권을 추측해 삭제하지 않음. 실제 계정 데이터는 테스트에서 접근하지 않음.
- 사용자 제공 숲·연못 지도 복구. 20260830 원화의 완성된 카페·병원과 대응 불빛만 같은 좌표로 추출. 미완성 그림이나 새 AI 그림은 추가하지 않음.
- 기기 로컬 시각 기준 새벽·낮·노을·밤. 위치정보/일출 계산이 아닌 고정 현지 시각 곡선을 사용.
- 건물별 18:00~06:00 기본 점등, 시간 편집, 항상 켜기/끄기. 같은 점등·소등 시각은 24시간 켜짐. 건물과 조명은 하나의 이동·반전·확대 계층.
- 부드러운 번짐은 CSS Gaussian blur로 표현. 분 단위 DOM 속성 갱신만 사용하고 화면이 숨겨지거나 마을이 없으면 타이머 중단.
- 태블릿에서 배치 도구가 상단 뒤로 밀리던 모바일 전용 기본 스타일을 공통 스타일로 이동.

## 검증

- 실제 state/auth 모듈 + 가짜 Firebase: A → 로그아웃 → B 초기화·2명 생성 → A 복귀, B 복원, 초기화 후 재실행, 늦은 다운로드/업로드 차단, 정상 같은 계정 업로드.
- 조명: 자정 넘김, 낮 시간대, 경계 분, 항상 켜기/끄기, 24시간 설정, 저장 복원, 이동·반전·확대 후 시간 유지.
- 384×854, 1180×820 브라우저 검수. 낮/노을/밤, 건물별 시간 입력, 영어/일본어, 반전·확대 후 원화와 조명 bounds 일치 확인.
- Android 모듈 18개 및 준비 자산 169개 검사, 웹 빌드, APK/AAB 빌드.
- 전체 npm 테스트 28종 중 24종 통과. 아래 4종은 HEAD의 수정 전 원문을 읽도록 실행해 동일 실패를 확인했고 이번 작업과 무관한 코드는 변경하지 않음.
  - catalog-routine: 오래된 엔진 버전 문자열 기대값.
  - backup-home-scene: 이전 상점 저장공간 조건 문자열 기대값.
  - character-wallet: 이전 설정책 좌표·페이지 구성 기대값.
  - town-grid: 이전 일러스트 선택창 존재 기대값.

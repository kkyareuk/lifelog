# 멀티 그룹 생성 화면 디자인용 메뉴

## 새 그룹 만들기
1. 뒤로가기 / 제목: 새 멀티 그룹
2. 내 프로필: 사진 + 유저 이름 (프로필 설정으로 이동)
3. 그룹 이름: 필수, 최대 40자
4. 마을 슬롯: 사용 중 / 전체 / 남은 개수 표시. 생성 시 1개 사용. 남은 슬롯이 없으면 생성 버튼 대신 슬롯 안내.
5. 첫 마을: 생성되는 마을 이름 표시. 생성 후 마을 정보에서 수정.
6. 권한 설정: 일반 구성원 / 운영자 / 관리자별 캐릭터 입주 한도. 방장은 관리 권한 유지.
7. 편집 권한: 역할별 마을·건물·집·장식 편집 가능 여부. 읽기와 방문은 편집 권한과 분리.
8. 집 방문: 그룹 구성원 방문 허용 여부.
9. 하단: 취소 / 그룹 만들기.

## 생성 완료 화면
- 생성한 그룹 이름, 초대 코드, 코드 복사
- 내 캐릭터 추가 / 그룹 마을로 들어가기
- 그룹 설정 열기

## 그룹 안 마을탭 메뉴
- 멀티: 현재 그룹 이름과 그룹 목록·전환
- 구성원: 이 그룹에 입주한 모든 캐릭터를 멀티 목록과 같은 카드 배치로 표시. 캐릭터 사진/이름/유저 사진·이름/거주 마을. 검색과 마을 필터.
- 마을 정보: 이름·소개·마을 특성
- 건물 정보: 건물/집 목록, 검색, 건물 추가, 집 추가
- 편집모드: 권한이 있으면 배치 편집, 없으면 잠금 표시

## 생성 후 그룹 설정
- 기본 정보: 그룹 이름
- 초대: 코드 표시·복사
- 유저 관리: 유저 사진/이름, 역할 지정, 내보내기
- 캐릭터 관리: 구성원 카드 목록, 입주와 퇴거
- 권한: 역할별 캐릭터 수/편집, 집 방문 허용
- 공식 관계: 보낸 제안/받은 제안, 수락·거절, 거절 사유
- 나가기: 방장 이외 사용자의 그룹 나가기

생성 화면에 모든 관리 목록을 넣지 않고, 생성에 필요한 입력과 생성 후 관리 화면을 나눕니다. 그룹 대표 이미지·소개문·공개 검색 노출 여부는 현재 생성 API에 없는 항목이므로 디자인 필수 항목에 포함하지 않았습니다. 새 디자인에서 원하면 별도 설정으로 추가할 수 있습니다.

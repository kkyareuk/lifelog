# 시키기 설정 전달·관계 반응·스와이프 점검

기준: origin/dev 3ff42c6. 작업 표식 dev305-log1. Android versionCode 305 / versionName 1.0.272 유지. 빌드 파일 배포·서버 배포·App Store 제출 없음.

## 확인한 원인과 변경

- 설정 → state → directCharacterActivity → lifeCopy 경로에서 생활 행동 문구 생성기에 캐릭터가 전달되지 않았다. 전체 캐릭터를 전달하고 집안일·요리의 계획 방식/행동 전환/대표 성격, 머리 감기·말리기의 실제 머리 길이에 연결했다.
- 관계 시선을 수정하는 updateCharacterView가 시뮬레이션 서명 캐시를 무효화하지 않았다. 양쪽 캐릭터의 미래 장면 입력을 갱신한다. 이미 시작한 시키기와 과거 기록의 문구는 바꾸지 않는다.
- 기존 viewDrivenInteraction은 두 사람의 시선 값을 합친 문자열에서 감정을 판정했다. ‘전혀 귀찮거나 성가시지 않음’을 성가심으로 읽고 ‘친구로 좋아함’을 연애 감정으로 읽을 수 있었다. 이 경로를 제거하고 방향별 구조화 판정으로 교체했다.
- 기분 계산에서 공식 부부 관계가 명시적으로 고른 ‘그저 그런 사람’을 덮었고, 과거 연인도 현재 연인 기본값으로 해석될 수 있었다. 현재 관계와 명시적 시선을 구별했다.
- 공식 관계의 그룹 구성원도 두 사람 사이의 관계를 조회할 때 포함한다. 한 번의 시뮬레이션 안에서는 관계 인덱스를 공유한다.
- 가구 주변 장면은 라이벌/혐관이라는 이름만으로 말다툼을 반복했다. 명시된 갈등 강도로 기회를 고르고, 동일 상대와의 최근 갈등에는 180분 간격을 둔다. 가구 장면이 이미 만들어진 섬세한 관계 반응을 덮지 않는다.
- 익숙하고 우호적인 양방향 관계에서는 기존의 구체적인 친밀한 장면도 유지한다. 불신·두려움·불편함·한쪽 감정은 각자의 반응으로 생성한다.
- 사회적 시키기는 대화·함께 시간 보내기·식사·차·술·함께 요리·토론 경로에 각자의 반응과 이전 장면에서 계산한 기분을 연결했다. 선택한 주제와 계산 방식은 유지한다. 선물·신체 접촉 허용·명시적 부정적 행동의 기존 계약은 유지한다.
- 시키기의 한국어·영어·일본어 문구를 기록에 함께 보관한다. 언어 전환 후 일반적인 대체 문구가 상세 반응을 지우지 않도록 했다.
- 홈 스와이프 선택과 렌더가 같은 시각/시뮬레이션 계산 묶음을 사용한다. 선택만 바뀔 때 우편함 네트워크 갱신과 전 주민 타이머 재계산을 반복하지 않는다.
- 웹 포장기의 오래된 캐시 검사와 고정 파일 목록 누락도 확인했다. 실제 import 의존성을 따라 필요한 모듈을 포함하고 현재 캐시 키를 검증한다.

## 시선 입력 범위

전체 인상, 중요도, 자기 감정 자각, 상대 마음 인지, 신뢰, 두려움, 친밀도, 함께 있는 편안함, 성가심, 관심, 질투, 갈등 강도, 관계 전망, 접촉 범위, 공격 충동, 공격 행동의 16개 필드를 구조적으로 읽는다. 장면에 관련 있는 후보를 고르며 모든 값을 문장에 나열하지 않는다. 직전 후보의 반복을 낮추고 일부 후보에는 별도 표현을 둔다. 말투 선택값을 바꾸거나 감정만으로 특정 말투를 강요하는 새 규칙은 없다.

범위의 한계: 모든 외형·건강·취향 선택지마다 새 장면을 집필한 작업은 아니다. 외형 추가 반영은 머리 손질, 혼자 하는 행동의 새 성격 반영은 집안일·요리 중심이다. 모든 캐릭터 조합의 서사 품질을 보장하는 것이 아니라 전달 경로와 확인한 오해석/반복 원인을 고친 1차 개선이다.

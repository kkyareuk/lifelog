# 개발판 184 — 사전 원화 UI·알림 우편 일치

- 버전: 1.0.171 / versionCode 184
- 날짜: 2026-08-31
- 앱 작업 브랜치: dev. 운영 main 또는 Google Play 배포가 아니다.

## 플레이어 변경사항

- 제공된 사전 SVG의 나무·종이·기울어진 책·뒤로 버튼·잉크병·갈색 버튼을 추출해 적용했다. 배경, 책, 입력 항목, 조작 버튼의 겹침 순서와 기준 좌표를 분리했다.
- 작은 화면은 시안처럼 3열, 넓은 화면은 6열 아이콘 목록이다. 이름·태그 검색, 종류·이용 장소 필터와 정렬을 제공하며 마지막에 물품 추가 버튼이 있다.
- 사진을 누르면 인게임 일러스트·이미지 링크·기기 업로드를 고를 수 있다. 별점은 0.5 단위이며 기존 값도 보존한다.
- 물품에 은은한 빛·반짝임·둥실둥실·살랑살랑을 지정할 수 있다. 해당 물품이 생활 장면의 소품으로 표시될 때도 효과를 사용한다.
- 서랍상점 간판에 목재 테두리와 금색 장식을 적용했다. 새 번들의 판매 상태는 변경하지 않았다.
- 알림을 예약할 때 제목·본문·대상·질문 종류를 함께 저장한다. 우편함과 알림 열기는 이 저장된 내용을 사용하며 받은 편지는 다시 생성하지 않는다.
- 건물·집 삭제 후 건물 목록으로 돌아가도록 선택 상태를 초기화했다. 마을 제목 위치를 위로 조정했다.
- 게임 버튼과 그림의 파란 터치 강조·이미지 길게 누르기 메뉴를 억제했다. 입력칸 선택과 붙여넣기, 키보드 포커스는 유지한다.

## 성능

- 사전은 처음 30개만 표시하고 더 보기로 확장한다. 선택한 항목만 편집하며 목록 효과는 미리보기 때만 움직인다.
- 숨겨진 모든 건물 상세창을 매번 생성하지 않고 선택한 건물만 만든다.
- 약 26 MB의 원본 SVG를 통째로 읽지 않고 추출한 WebP 5개(총 약 370 KB)를 사용한다.
- 실제 Android 기기의 FPS·메모리·체감 렉은 추가 기기 검증이 필요하다.

## 검증

- 격리된 메모리 저장소의 가상 마을로 브라우저 검수. 실제 계정 데이터를 수정하지 않았다.
- 412×917 한국어 목록·편집 화면, 360×800 일본어 편집 화면, 1024×768 영어 6열 목록 확인. 문서 및 편집 영역의 가로 넘침 없음.
- 이름·맵기·별점 3.5·효과 저장 후 재열기, 검색, 사진 선택 3가지 메뉴와 인게임 일러스트 반영 확인.
- 건물 삭제 후 목록 복귀, 초기 숨김 상세창 0개 확인.
- 저장된 우편의 제목·본문을 목록과 상세창에서 동일하게 확인.
- 터치 강조색 transparent, 그림 버튼 선택 none, 입력 선택 auto 확인.
- 새 dictionary184 회귀 검사 통과. 전체 32종 중 29종 통과.
- 기존 실패 3종 유지: backup-home-scene(이전 50MB 상품 기대값), character-wallet(이전 책 배치 기대값), town-grid(제거된 마을 일러스트 선택기 기대값). 해당 기능을 이번 수정에서 되돌리지 않았다.
- app:sync, 웹 빌드, Android assembleDebug 및 bundleRelease 성공. APK 내 app.js·dictionary.js/CSS·notification-mail.js·책 이미지와 www 원본의 SHA-256 일치 확인.
- Android 실기기의 실제 알림 도착·탭 복귀, 기기 파일 선택은 미검증. 새 상점 간판의 최종 실기기 외관도 추가 검수가 필요하다.
- 정적 UI 번역: 영어 1912/2598(73.6%), 일본어 1911/2598(73.6%). 전체 생활 로그나 사용자 작성 텍스트의 번역률이 아니다.

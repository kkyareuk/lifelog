# 1.0.356 (408) · 팝업 위치 / 마피아 선택·연출·추리

개발 dev. 새 마피아 게임에 규칙 v3 적용. 진행 중인 v1/v2 게임은 기존 규칙을 유지한다.

- 캐릭터 팝업을 visual viewport와 원래 캐릭터 위치에 맞춰 다시 배치한다. 내용 증가·화면 크기 변경·키보드 영역 변화 때 화면 안에 유지한다.
- 이동 선택45초 → 걷기 연출3.5초 → 행동 선택45초 → 결과 연출6초. 선택 시간과 연출 단계가 분리된다.
- 모든 직접 참가자가 선택하면 즉시 전환. 한 사용자와 NPC 조합은 선택2초 후 전환한다.
- 진행 확인과 행동 제출이 화면 전체를 로딩 문구로 교체하지 않는다. 같은 단계의 화면·카드 선택을 유지한다. 상태가 바뀌지 않은 진행 조회는 서버에 다시 저장하지 않는다.
- 마을 건물 그림·좌표, 집의 방 배치·바닥·가구 렌더러를 사용한다. 건물·가구·캐릭터를 눌러 선택한다.
- 살해 우선 연출, 현장의90도 시신 표시, 피해자 관전. 첫날에도 단둘인 시민을 하루1회 습격할 수 있다.
- 마피아 전용 익명 인원수, 임무 집중 장소, 직전 혼자 있었던 건물 정보.
- 회의 전 알리바이 정비: 가진 카드에서 함께 있었음 / 방문했던 건물 / 기억 안 남을 선택한다. 미제출 시 자동 선택한다.
- 한 명씩 말투를 적용한 알리바이를 말한다. 모순되는 카드를 가진 사람만 지적 예약을 할 수 있고 첫 예약자가 발언 뒤 근거 카드를 낸다.
- 추리 SVG의 참가자 줄·발언 캐릭터·말풍선·끼어들기·하단 손패 구성. 제공받은 종이 그림을 카드에 사용한다.
- 결과 단계에서 새 카드 획득 연출과 짧은 설명을 표시한다.

## 마피아 첫 버전
- 광장에서 멀티 선택 → 방장/관리자가 개설, 4~10명(기본5), 단계별6/12/24시간. 실제 마을/집의 장소3~8개를 선택 순서의 원형 동선으로 연결.
- 사용자당 직접 조종 1명. 빈자리는 소유자가 미리 자동 참가 허용한 캐릭터만 충원. NPC도 시민/마피아 배정.
- 이동·임무·조사6칸 계획을 동시 제출. 미제출/NPC 계획은 자동. 방해·술래 지목은 마피아 전용. 밤에는3회 이동, 늦게 자는 캐릭터는 첫 밤 목격 가능.
- 자기 알리바이/목격/흔적 카드, 공개 카드 보드, 장소 진술 충돌 표시. 카드 공개·의심·옹호·보류, 의심에 자동 알리바이 반박. 마피아는 하루1회 위조 가능, NPC 위조 선택 포함.
- NPC 의심은 자기 카드·공개 기록과 약한 기존 시선 가중치만 사용. 대상의 숨은 역할을 읽지 않음. 기존 말투 변환으로 대사 표시.
- 토론3단계→투표, 동률 유보. 임무100%/마피아 전원 퇴장 시 시민 승, 마피아 수가 시민 이상이면 마피아 승.
- 서버 절대 마감 시간·트랜잭션으로 중복 처리 방지. 재접속 시 지난 단계 최대50회 따라잡기. 종료 시 원래 관계에 쓰지 않고 잠깐의 기분 효과만 적용. 주최 취소/참가 철회 제공.
- 홈 원형 표시는 선택한 멀티의 실제 참여 놀이. 게임 자체 상태는 참가 멀티의 서버 API에서 확인.
- 계정 삭제 시 다른 멀티에 남은 게임의 해당 계정 이름·개인 카드·제출을 정리.

## 첫 버전의 범위 / 후속
- 솔로·무도회·음악회·요리·서바이벌·릴레이·보드게임은 미구현.
- 실제 마을 좌표 기반 길 찾기, 감각별 흐릿한 기억, 고급 모순 종류, 대사100종, 라운드 우편 알림, 장기 기록 정리와 상세 리플레이는 후속.
- 토론은 비동기 동시 제출 방식. 누구도 접속하지 않을 때 서버 크론이 매번 진행하는 방식은 아니며, 놀이를 열면 서버가 마감 상태를 따라잡음.
- 실제 사용자 여러 기기의6~24시간 왕복과 재미/밸런스는 미검증. 서버 시뮬레이션과 격리 UI fixture로 검증한 초기 플레이 버전.

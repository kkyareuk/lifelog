# Android 1.0.204 · versionCode 219

2026-09-05 `dev` 준비판. 이전 [218 준비판](android-release-218.md)의 관계 편집·마을 산책 개선과 그 이전 변경사항을 모두 포함합니다. 운영 `main`, 웹사이트, Play Console 배포는 변경하지 않았습니다.

## 파일

- 바로 설치용 APK: `drawer-village-v1.0.204-code219-dev-debug.apk`
- Play Console 업로드용 AAB: `drawer-village-v1.0.204-code219-dev-release.aab`
- APK SHA-256: `9504F897D90545E4877BCA4B4A1C72EDE149FB0FA8D455C693B2785F7D318051`
- AAB SHA-256: `1ED3387FAE48BBA8F70D6A99C1CC67EB2807667B9A7A1875AA4DF3CB977271C2`
- Android 빌드 메타데이터 `versionCode 219` / `versionName 1.0.204`를 확인했습니다. release AAB의 서명은 jarsigner `jar verified`/종료 코드 0이며, 준비 자산 214개와 번들 내부 파일 SHA-256이 모두 일치합니다.
- 자체 서명 체인·타임스탬프 없음 및 ZIP 엔트리 순서 관련 jarsigner 경고는 있습니다. Play Console 업로드 검증은 아직 하지 않았습니다.
- Play에 이미 219 이상을 올렸다면 이 AAB를 올리지 말고 더 큰 versionCode로 다시 빌드해야 합니다.

## 변경 내용

- 마을 전체 산책 캐릭터도 발소리 대상에 포함했습니다. 걷기 스타일별 보폭에 맞춰 소리 간격과 재생 속도가 달라지며, 음소거·효과음 음량 설정은 그대로 적용됩니다.
- 마을 산책의 기본 이동 시간을 늘려 보통 걸음이 급하게 보이지 않도록 했습니다. 조심스러운 걸음부터 빠르고 성큼성큼 걷는 걸음까지 속도와 몸 움직임이 각각 달라집니다.
- 신규 걸음걸이 `그림자처럼 매우 민첩하게`를 추가했습니다. 가장 짧은 이동 시간, 빠른 스텝 애니메이션, 달리기 계열 발소리를 사용합니다.
- `법적 등록 여부`를 부부뿐 아니라 부모·자녀와 형제·자매 관계에도 제공합니다. 기존 부부 데이터는 새 공통 필드로 안전하게 이전합니다.
- 태블릿 가로형 캐릭터 화면의 캐릭터 목록과 넓은 2열 디자인은 유지하면서, 오른쪽 편집 내용은 스마트폰 전체설정과 동일한 7개 탭(사진·색상·배치, 개요, 신체, 의상 취향, 성격, 취향·소지품, 옷장)을 그대로 사용합니다. 같은 상태와 저장 이벤트를 공유하므로 기기 방향별 설정이 갈라지지 않습니다.

## 검증과 남은 확인

- 걸음 속도 순서, 스타일별 애니메이션·발소리 간격, 마을 산책 발소리 선택, 가족 관계 3종의 법적 등록 저장, 태블릿과 스마트폰의 7개 페이지 공유를 `scripts/check-gait-tablet-219.mjs`로 검사했습니다.
- 관계 편집·마을 전체 산책·발소리·캐릭터 설정·선택 상태 유지·신고 오류 13종·홈 생활 시뮬레이션 70종 회귀 검사를 통과했습니다.
- Android debug APK와 release AAB를 clean build했고, Android 패키지의 214개 준비 자산 일치 및 APK 버전 메타데이터를 확인했습니다.
- iOS 준비본도 동일한 웹 모듈과 오디오를 동기화하고 프로젝트 검사를 통과했습니다. 실제 Xcode 빌드·서명·실기기 검증은 Mac에서 남아 있습니다.
- 전체 UI 정적 번역률: 영어 2082/2770(75.2%), 일본어 2081/2770(75.1%). 이번에 추가한 걸음걸이 및 관계·태블릿 사용자 문구는 영어·일본어에 함께 반영했습니다. 이 수치는 동적 생활 로그 전체의 번역률은 아닙니다.
- Play Console 업로드·프로덕션 제출은 아직 하지 않았습니다. 새 화면과 동작은 219 APK를 설치하거나 219 AAB를 배포한 뒤에만 기기에 나타납니다.

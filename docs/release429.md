## 적용 내용

- 투명 원화의 가구 경계만 잘라 화분 2, 협탁, 카운터, 연결형 카운터, 상판, 냉장고 정면/측면, 인덕션을 추가했다. 원본 그림과 알파를 유지했다.
- 카운터를 옆 카운터 가장자리로 붙이는 배치 스냅을 추가했다. 연결 전체를 한꺼번에 이동하는 그룹 기능은 아니다.
- 카운터·협탁 소품을 가구 그림 안의 상판 영역에 배치하여 함께 이동·반전되도록 했다. 인덕션은 빈 카운터 상판 전체를 사용하며 다른 소품과 중복되지 않는다.
- 침실은 용변·식사·조리·위생, 주방은 수면·용변·위생 등 방 용도별 기본 제한을 적용했다. 과거 전체 허용 기본값은 새 기본값을 따르고, 사용자가 일부 조정했던 제한 목록은 유지한다. 앞으로 직접 저장한 전체 허용도 사용자 선택으로 보존한다.
- 자동 수면 전체 금지와 별도로 낮잠/부족한 수면 보충 금지를 추가했다. 명시적인 수동 행동과 정규 수면은 낮잠 금지 대상과 구분한다.
- 식사·용변의 실제 행동 의미를 우선하여 이전 수면 상태나 ‘수면 부족’ 기분 문구로 침대에 누운 모습이 남는 오류를 수정했다. 침대 아이콘은 12% 확대했다.
- 본가를 변경할 때 실제 집의 마을·유효한 침실 연결도 갱신한다. 내용이 짧은 본가 제보의 정확한 재현 사례는 확인하지 못했다.
- 제공된 버튼 소리와 일반 걸음/구두/부츠 소리를 연결했다. 효과음 음량·음소거를 따르고 선택 반응을 추가했다. 단일 드롭다운은 검색 가능한 선택 팝업으로 연결하며 원래 선택 값과 변경 이벤트를 유지한다.
- 마피아 증거 불충분은 증거 없이 주장에 반대하는 반응이다. 관련 없는 제3자의 증거를 반박·의심·변호에 붙이는 경로를 제한했다. 이름 뒤 한국어 조사를 수정했다.
- 3일차부터 NPC는 생존 후보에게 투표한다. 사용자의 기권/추방 없음과 동표 무탈락은 유지한다.
- 발자국·구두/부츠 흔적과 조건부 야간 실루엣 단서를 추가했다. 단서가 범인 신원을 확정하지 않도록 했다. 시민으로 신뢰받거나 증거를 내는 상대, 충동적인 캐릭터의 원한을 밤 표적 선택에 반영했다. 지능이 높고 충동성이 낮으면 원한 보정을 제외한다.
- 판 전용 감정에 따른 긴장·분노·호의 연출과 반응 애니메이션, 반박/동조/넘기기 버튼 영역을 확대했다. 종료 회고에서 작위적인 슬픔 같은 주관적 판단을 확정 관찰에서 제외한다.

# 개발판 1.0.172 · versionCode 185

앱 작업 브랜치: dev. 운영 main·Google Play 배포는 포함하지 않는다.

## 변경

- 같은 마을을 동기화할 때 건물 목록 전체를 덮어쓰던 경로를 건물 ID 단위 병합으로 수정했다. 양쪽 삭제 기록이 우선하며 서로 다른 마을의 건물은 섞지 않는다.
- 불러온 활성 world에만 있는 건물도 towns 정규화에서 보존한다.
- 건물 목록의 ‘건물 복구’에서 현재 계정의 복구본에만 남은 건물을 미리 보고 선택 복구한다. 일반 저장이 이전 안전 사본을 갱신하기 전 소실 건물 기록만 따로 보존한다. 초기화 이전 저장본·삭제 기록·다른 계정은 제외한다. 실제 사용자 계정의 복구 성공을 확인한 것은 아니다.
- 건물 목록을 종이 테두리/카드, 휴대폰 3열·넓은 화면 6열, 검색·필터·항목 수·마지막 추가 칸으로 정리했다. 상세 편집의 overflow:hidden을 해제했다.
- 애니메이션 위치는 캐릭터 탭에서 고른다. 반드시 왼쪽, 되도록 왼쪽, 무작위, 되도록 오른쪽, 반드시 오른쪽. 기존 관계의 배치 설정은 캐릭터가 명시적으로 선택하기 전까지 이전 값으로 읽는다. 실제 애니메이션의 참가자 순서에도 적용한다.
- 10페이지는 클릭을 차단하던 부모 스타일을 고려해 버튼 영역을 활성화하고 책 안쪽 좌표로 배치했다. 관심사·취미·기술 선택 때 전체 화면을 다시 만들지 않고 선택 상태와 요약만 갱신한다.
- 상점 상품과 탭은 목재/금색 간판 분위기로 정돈했다. 상품·가격·결제 정책·신규 번들 판매 상태는 변경하지 않았다.
- 선택 버튼을 노란색 입체 스타일로 변경했다. 마을 정보의 배경은 선택한 마을 원화를 흐리게 표시한다.
- 사전의 제공 일러스트는 전체 비율, 사용자 사진은 정사각형 크롭/둥근 모서리로 구분한다. 사용자 사진의 배경을 임의 제거하지 않는다.
- 관찰 화면의 현재 기분 버튼에서 점수와 원인을 확인한다. 현재 마을/건물 평판·분위기·휴식·갈등을 반영하는 파생 값이며 렌더링 횟수에 따라 누적되지 않는다. 공동 장면의 대화에 건물 분위기/마을 평판을 반영하고 양쪽 인물이 같은 대화 원문을 공유한다.
- 집으로 새로 진입할 때 이전 편집 모드를 유지하지 않는다. 보고된 집 진입 불가 자체는 가상 데이터에서 재현되지 않아 실계정 재확인이 필요하다.

## 검증

- 신규 village185 검사: 동일 마을의 소실 건물 보존, 삭제 우선, 마을별 분리, 반복 병합, 선택 복구, 계정 분리, 캐릭터 배치 저장, 기분 결정성과 양/음수 변화 통과.
- 신규 검사를 포함한 전체 33종 중 30종 통과(기존 32종 중 29종 통과). 기존 기대값 불일치 3종: backup-home-scene(예전 상품 기대값), character-wallet(예전 책 구조), town-grid(제거된 마을 일러스트 선택기). 이번 변경을 숨기기 위해 해당 검사들을 삭제하지 않았다.
- 격리된 가상 데이터로 10페이지 6개 버튼과 팝업 열기, 관심사 저장 유지, 기분 이유 팝업, 캐릭터 위치 팝업, 건물 목록 및 선택 복구 확인.
- 가상 도서관이 복구 후 목록과 지도 양쪽에 표시됨을 확인. 건물 상세 편집의 scrollHeight 982 / clientHeight 736 / scrollTop 246.7로 하단 이동 확인.
- 마을 정보에서 실제 배경 이미지의 블러 표시 확인. 캐릭터 9명의 가상 저장 상태에서도 집의 편집/관찰 화면 열기를 확인했으나, 사용자 실계정의 진입 오류는 재현하지 못했다.
- 384×854 휴대폰과 1024×768 태블릿에서 건물 목록 검수. 모바일 전용 스타일과 중복 태블릿 목록 스타일을 공통 구조로 합쳤고, 카드 이미지가 이름을 덮지 않게 높이를 제한했다. 360×800 일본어 기분 팝업·사전 이미지 contain/cover 구분, 영어 기분 설명 확인.
- PC 합성 벤치마크(캐릭터 12명, 추가 사전 물품 300개): 최초 약 33.5ms, 반복 약 10.6~11.9ms. Android 실기기의 FPS나 지연시간 측정치는 아니다.
- 웹 준비·Android 모듈 의존성/182개 자산 검사·APK/AAB 빌드 성공.
- 정적 UI 번역: 영어 1921/2607(73.7%), 일본어 1920/2607(73.6%). 이번 새 기능의 문구는 양 언어로 제공한다. 전체 생활 로그/사용자 입력 번역률은 아니다.

## 설치 주의

이 개발판을 설치하려고 기존 앱/데이터를 삭제하지 말 것. 서명 불일치 시 같은 배포 경로를 사용해야 한다.

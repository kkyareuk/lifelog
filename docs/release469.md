## 구현 및 검증
- Chrome/WebKit: 새 집 기본 12열 전체 폭, 빈 마을 제목 상단바 내부, 멀티 캐릭터 빈 화면 단순화.
- Chrome/WebKit 실제 모듈: 선택한 멀티 캐릭터 공유코드 적용, 개인 캐릭터 수/집/제작 소지품 보존.
- 커피머신: 캡슐·에스프레소·아메리카노·아이스·휘핑 우유·라떼·카푸치노·청소. 제작 완료 후 소지품, 휘핑 우유 소비, 서버 스냅샷 재계산 중복 지급 방지 검증.
- 기존 및 승인 대기 합산 정원, 동시 요청, 관리자에게 복제된 승인 요청 중복 집계 방지, 이사/생성/운영진 정원 검증.
- 집 편집 임시 목록이 최신 삭제·인테리어를 덮지 않도록 수정. 저장 완료 서버 응답 즉시 반영 및 오래된 응답 차단 검증.
- 이사 요청의 그룹/마을/요청 ID를 고정하고 화면 이동과 분리. 계정 변경은 계속 차단.
- 개인 캐릭터 0명일 때 로그인 사용자에게 멀티 이어하기 제공. 제보자의 데이터 복구 완료라고 단정하지 않음.
- 360px 가구 편집/층 버튼 회귀, iOS 실제 인증 및 플랫폼 분리 통과.
- 기존 check-shared-town-service는 과거 사전 80개 제한을 기대해 실패. 이번 작업에 맞춰 임의로 전체 테스트를 통과 처리하지 않음. 현재 100개 한도와 별도 정원·동기화 검증을 사용.
- 전체 정적 번역 EN2260/2988, JA2259/2988: 모두75.6%. 새 문구·커피 내용은 한국어/영어/일본어 제공.

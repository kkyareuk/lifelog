# Android 1.0.204.1 · versionCode 220

2026-09-05 프로덕션 219의 긴급 안정화 핫픽스입니다. 실제 출시 중인 219 소스를 `main`에 맞춘 뒤 수정했으며, 같은 변경을 `dev`에도 반영합니다. Play Console 업로드와 프로덕션 심사 제출은 사용자가 진행해야 합니다.

## 파일

- 바로 설치용 APK: `drawer-village-v1.0.204.1-code220-hotfix-debug.apk`
- Play Console 업로드용 AAB: `drawer-village-v1.0.204.1-code220-hotfix-release.aab`
- APK SHA-256: `3A70BA6BBD60AA0855DA893600760E1C1B833B3DE04E93E68E7541EA53698DE2`
- AAB SHA-256: `95A6A88C220CA85AFC3C3948F10F765CD46EBF3E969FB019193133C0FD91D90D`
- Android 빌드 메타데이터 `versionCode 220` / `versionName 1.0.204.1`을 확인했습니다.
- release AAB 서명은 jarsigner `jar verified`/종료 코드 0이며, 준비 자산 214개와 번들 내부 파일 SHA-256이 모두 일치합니다.
- 자체 서명 체인·타임스탬프 없음 및 ZIP 엔트리 순서 관련 jarsigner 경고는 있습니다. Play Console 업로드 검증은 아직 하지 않았습니다.
- Play Console에 이미 220 이상이 올라가 있다면 이 AAB를 올리지 말고 더 큰 versionCode로 다시 빌드해야 합니다.

## 변경 내용

- 캐릭터 메뉴를 누르면 중간 선택 화면을 거치지 않고 항상 전체설정으로 바로 이동합니다. 새 캐릭터 생성 뒤에도 같은 전체설정을 엽니다.
- 스마트폰과 태블릿의 전체설정 뒤로가기 버튼을 공통 메뉴 이동 경로에 연결했습니다. 태블릿에서 숨겨져 있던 뒤로가기 버튼도 다시 표시합니다.
- 전체설정 화면에서는 보이지 않는 캐릭터 허브·구형 편집기·중복 태블릿 편집기를 함께 생성하지 않습니다. 캐릭터가 많을수록 커지던 화면 생성량과 탭 전환 지연을 줄였습니다.
- 전체설정 메뉴 안에서 빠른설정을 선택할 수 있으며, 저장하거나 닫은 뒤 전체설정으로 돌아옵니다.
- 빠른설정의 글꼴을 별도 명조체로 강제하지 않고 사용자가 고른 앱 UI 글꼴과 동일하게 표시합니다.
- 마을 전체 산책은 지원 기기에서 매 프레임 `left`·`top` 레이아웃을 다시 계산하지 않고 합성 애니메이션으로 이동합니다. 기존 기기용 동작은 대체 경로로 유지합니다.
- 걸음 발소리 재생 때마다 캐릭터별 위치·스타일을 강제로 다시 계산하던 처리를 제거해 마을 화면의 끊김과 발열을 줄였습니다.
- 캐시 식별자를 220 전용으로 교체해 이전 화면 모듈과 새 모듈이 섞이지 않게 했습니다.

## 검증

- 캐릭터 직접 전체설정 진입, 빠른설정 접근, 공통 뒤로가기, 빠른설정 글꼴, 숨은 중복 편집기 미생성, 합성 산책 경로와 발소리 레이아웃 읽기 제거를 `scripts/check-hotfix-220.mjs`로 검사했습니다.
- 메뉴 이동 경계 9종, 성능·발열 안정성 10종, 걸음걸이·가족 관계·태블릿 캐릭터 회귀검사를 통과했습니다.
- Android debug APK와 release AAB 빌드를 통과했고, Android 패키지의 준비 자산 214개가 서명 AAB와 바이트 단위로 일치함을 확인했습니다.
- 전체 UI 정적 번역률: 영어 2081/2769(75.2%), 일본어 2080/2769(75.1%). 이번 핫픽스는 기존 번역 문구를 재사용해 새 미번역 사용자 문구를 만들지 않았습니다. 이 수치는 동적 생활 로그 전체의 번역률은 아닙니다.
- 실제 Galaxy 기기의 기존 219 설치본 위 업데이트와 장시간 프레임 체감 확인은 Play 배포 전 마지막 확인으로 남아 있습니다.

# Android 1.0.203 · versionCode 218

2026-09-05 `dev` 준비판. 이전 [217 준비판](android-release-217.md)의 관계 편집 개선과 그 이전 변경사항을 모두 포함합니다. 운영 main/웹사이트/iOS 배포 및 Play Console 업로드는 변경하지 않았습니다.

## 파일

- 바로 설치용 APK: `drawer-village-v1.0.203-code218-dev-debug.apk`
- Play Console 업로드용 AAB: `drawer-village-v1.0.203-code218-dev-release.aab`
- APK SHA-256: `7F29D7A4E96D81AA64684339088C3308DB36F8C03680646DDEB5527C0DADABD7`
- AAB SHA-256: `839F578FD629F21DA363F076C443F569406729D82FA65A009F1657F69EBFEE44`
- Android 빌드 메타데이터 `versionCode 218` / `versionName 1.0.203`을 확인했습니다. release AAB의 서명은 jarsigner `jar verified`/종료 코드 0이며, 준비 자산 213개와 번들 내부 파일 SHA-256이 모두 일치합니다.
- 자체 서명 체인·타임스탬프 없음 및 ZIP 엔트리 순서 관련 jarsigner 경고는 있습니다. Play Console 업로드 검증은 아직 하지 않았습니다.
- Play에 이미 218 이상을 올렸다면 이 AAB를 올리지 말고 더 큰 versionCode로 다시 빌드해야 합니다.

## 변경 내용

- 관계 편집 화면을 모바일 세로 스크롤 카드 구조로 다시 배치해 캐릭터가 많아도 선택 목록과 설정이 겹치지 않게 했습니다.
- 관계에 선택한 모든 캐릭터를 순서 목록에 표시하고, 각 행의 위·아래 버튼으로 전체 표시 순서를 바꿀 수 있습니다.
- 부부의 법적 등록 여부를 “관계가 밖에서 다뤄지는 방식”과 분리된 별도 체크 항목으로 만들었습니다. 기존 216 데이터도 새 필드로 자동 이전합니다.
- 분수 등 한 장식에 여러 캐릭터가 방문하면 장식 둘레의 서로 다른 자리에 나누어 표시합니다. 장식 방문 중에는 좁은 원을 계속 걷지 않고 그 자리에서 장식을 구경합니다.
- 장식 방문 비율을 낮추고, 마을 특성 산책 장면은 지도 전체의 길·시설·집 주변을 잇는 여러 순환 동선으로 표시합니다. 캐릭터별 시작 지점·속도·출발 시차도 달라집니다.

## 검증과 남은 확인

- 캐릭터 13명인 384×854 관계 편집 화면의 전체 스크롤, 구성원 선택·순서, 외부 공개·법적 등록, 동거 설정과 저장 영역 사이의 간격을 확인했습니다.
- 관계 편집 구조와 데이터 이전은 `scripts/check-relationship-editor-217.mjs`, 장식 방문 분산과 마을 전체 산책 동선은 `scripts/check-town-walking-218.mjs`로 검사합니다.
- 전체 UI 정적 번역률: 영어 2086/2774(75.2%), 일본어 2085/2774(75.2%). 마을 산책에는 새 사용자 문구가 없고, 관계 편집 신규 문구는 영어·일본어 모두 포함되어 있습니다. 이 수치는 동적 생활 로그 전체의 번역률은 아닙니다.
- Play Console 업로드·프로덕션 제출은 아직 하지 않았습니다. 새 화면과 산책 동선은 218 APK를 설치하거나 218 AAB를 배포한 뒤에만 기기에 나타납니다.

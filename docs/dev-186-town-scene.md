# 개발판 1.0.173 · versionCode 186

앱 작업 브랜치: dev. 운영 main·Google Play 배포는 포함하지 않는다.

## 변경

- 로그인 직후 계정 전환·자동 불러오기가 끝나기 전에 빈 저장으로 판단해 신규 캐릭터·마을 만들기를 띄우던 시작 순서를 차단했다. 저장 계정을 확인하는 동안은 전용 대기 화면을 유지한다.
- 실제 `towns` 목록이 있으면 활성 화면용 `world` 복제본을 건물 병합 원본으로 다시 사용하지 않는다. 동기화 중 같은 건물 ID가 여러 마을에 생기면 명시된 소유 마을, 정상 스냅샷, 직장 위치를 비교해 한 마을에만 귀속한다.
- 캐릭터 전체설정 3페이지 위쪽에 애니메이션 위치를 배치했다. 관계 화면이 아니라 캐릭터별로 반드시/되도록 왼쪽, 무작위, 되도록/반드시 오른쪽을 설정한다.
- 캐릭터 전체설정 1페이지에 상태별 아이콘·LD 메뉴를 추가했다. 수면, 아침 준비, 목욕·욕실, 근무, 외출, 기쁨, 슬픔, 화남, 피곤함 이미지를 SD/LD별로 등록한다. 장면과 일치하는 이미지가 없으면 기본 아이콘·LD를 사용한다.
- 마을 건물 목록에서 `건물 추가`와 `집 추가`를 분리했다. 집 추가는 현재 마을에 집을 만들고 곧바로 외형·마을 위치·크기·평판·분위기·불빛을 편집한다.
- 집 화면 설정은 집 이름·용도·층수·소유·거주와 내부 생활 정보만 다룬다. 집 외형과 지도 배치는 마을의 건물 정보에서 편집한다.
- 사용자가 제공한 원본 스프라이트 시트에서 피아노 음악당, 공원, 빨간 지붕 집과 각각의 불빛 레이어를 투명 PNG로 분리했다. AI 생성이나 재그림은 사용하지 않았다. 불빛은 건물과 같은 좌표·크기·반전에 묶이고 현실 시간/건물별 점등 시간에 따라 표시된다.
- 앱 버전을 1.0.173 / 186으로 올리고 캐시 표식을 `20260901scene186`으로 갱신했다.

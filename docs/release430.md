## 적용 내용

- 카운터는 끝부분을 유지하는 3슬라이스 그림으로 그리며 선택 도구의 길이 조절(1~6, 0.25 간격)로 가운데를 늘린다. 여러 개 사이의 외곽선 반복 대신 긴 카운터 한 개를 만들 수 있다. 별도 L자/코너 자동 생성 기능은 아니다.
- 잘못 등록했던 카운터 상판/연결형을 카운터의 옆/뒤 방향으로 마이그레이션한다. 기존 회전 그림의 파일명과 카탈로그도 바로잡았다. 원본 픽셀은 변경하지 않았다.
- 실제 가구를 카운터 상판의 4×길이, 세로3칸 격자에 끌어 붙인다. 협탁은 중앙1칸이며 이미 가구가 있으면 중복 배치를 받지 않는다. 침대/소파/큰 수납장 같은 가구는 대상에서 제외한다.
- 배치된 물건은 상판을 부모로 기록하고, 이미지 밑부분을 상판에 맞추며 부모보다 앞에 그린다. 받침 가구를 다른 방으로 옮겨도 함께 이동한다. 기존 메뉴형 상판 소품은 실제 배치로 전환한다.
- 이름 숨김 옆 위로/아래로 옮기기 버튼으로 가구 목록·숨김·회전/길이 도구를 하나의 묶음으로 이동한다. 기존 선택 가구 위치에 따른 임의 도구 이동 로직을 제거했다.
- 멀티 편집 완료는 현재 초안을 다시 저장한다. 이전 저장 실패로 완료가 계속 막히던 경로에서 오류를 알리고 재시도할 수 있게 했다. 저장 전까지 초안을 유지한다.
- 소파 캐릭터는 투명 여백을 제외한 그림의 좌석 기준점을 맞춘다. 같은 상호작용의 문구는 하나로 묶고 고민/대화 주제를 보존한다.
- 사진 업로드 전에 원본 SHA-256으로 기존 업로드를 찾는다. 현재 저장본 기준 한도 계산과 기존 업로드 조회 목록을 분리해, 부분 공유 저장에서 이전 사진을 재사용하지 못하던 경로를 수정했다. 기존 압축 결과 해시도 호환 조회한다.

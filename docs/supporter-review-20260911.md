# 후원자 명단 확인 · 2026-09-11

대기 신청 3건을 읽고 서버 구매 권한과 공개 이름을 확인하여 승인했다. 공개 API에서 제논, Q, 주검의 반영을 확인했다. 사용자에게 별도 우편·푸시는 발송하지 않았다. 비공개 식별자와 구매정보는 기록하지 않는다.

매주 일요일 오전9시(한국시간) 정기 검토를 기존 예약에 추가했다. 기존 9월14일00:05 슬롯전환 확인은 RDATE로 유지한다. 애매한 신청은 보류하고 알린다.

후원자 신청 화면과 접수 완료 문구에 매주 일요일 확인 후 반영 안내를 KO/EN/JA로 추가했다. 이 문구는 소스에 반영되었으며 330 APK/AAB에는 포함되지 않는다. 이번 운영 명단 반영은 온라인 API에 적용되어 앱 재빌드가 필요하지 않다.

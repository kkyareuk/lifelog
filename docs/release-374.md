# Android 1.0.328 (374)

Seated chair/sofa icons reduced about 12%; standing icons unchanged. Seat-only width fixes alignment with hidden status/speech. Eating presentation now uses an activity motion. Chair frame shares art geometry and participates in drag preview. Linked table/chairs move atomically across rooms, retaining offsets; automatic snap faces the table. Toolbar room destination removed, magnet control compact. Town/group selectors retain shape with dropdown markers; dining room Korean label migrated.

Validated Chrome mobile touch: personal/shared cross-room dragging, stable preview size, depth ordering, overlap selection, magnet toggle, frame and linked group preview cleanup, grouped persisted move, seated center/width and hidden labels/eating animation. Synthetic geometry is not physical device visual verification. Android APK/AAB built; version374, APK signature and bundled modified modules verified. iOS374 project prepared and project checks passed; no Mac archive, upload or physical iPhone verification. Existing mobile startup/lag remains unconfirmed. New scoped labels use existing EN/JA translations (100%); whole-app coverage not measured.

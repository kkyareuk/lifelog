# 내부 1.0.440 (492)

## 변경
- 네오 테마의 전역 버튼 배경 적용을 설정 패널로 제한. 건물·가구 원화, 뒤로가기, 집·마을 제목, 나무 버튼의 투명 영역 보존.
- 완성 음식 버튼을 일반 버튼 스킨에서 제외하여 흰 네모 제거.
- 크림색 캐릭터·반려동물 이름표에 어두운 텍스트 유지.
- 카운터 자체와 상판 도구 사용자 모두 카운터 앞 바닥에 배치. 서 있는 사람·반려동물은 가구보다 앞에 표시.
- 실제 그림 영역을 기준으로 방 안의 서 있는 캐릭터·반려동물 빈자리 탐색. 사용하는 가구 및 지지 가구는 예외, 침대·의자 전용 자세 유지.
- 반려동물의 짧은 이동 범위도 예약. 같은 활동 재렌더링의 자리 안정성 유지.
- 침대 오버레이가 다른 가구의 크기 판정에 섞이는 오류 수정.

## 범위
실내 정지 위치 배치 개선이다. 이동 경로 전체의 물리 충돌/길찾기 구현은 아니다. 가구로 꽉 차 빈자리가 없는 방은 겹침이 가장 적은 자리를 선택한다. 사용자가 놓은 가구 자체를 임의 이동하지 않는다. 저장 데이터·서버 스키마 변경 없음.

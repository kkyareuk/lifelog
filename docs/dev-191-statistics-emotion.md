# dev 1.0.178 (191) 통계·정서·달력 정리

## 새 월드와 사전

- 새 월드의 사전은 모든 카테고리를 빈 목록으로 시작한다.
- 기존 월드에서 사용자가 저장한 사전 항목은 마이그레이션 중 지우지 않는다.
- 기본 카페와 음식점의 판매 목록도 새 월드에서는 비워 둔다.

## 캐릭터 설정

- 9쪽의 기분·정서 성향은 8개 항목으로 정리했다.
- 분노할 때의 반응과 유혹·호감 신호를 받을 때의 반응을 기분 계산에 사용한다.
- 1쪽의 테마 선택은 캐릭터 대표 색상과 분리된 전체 메뉴 테마 선택이다.
- 고급 LD 버튼은 옷장으로 바로 이동한다.
- 옷장 SD와 LD는 옷 레이어가 아니라 캐릭터 그림 전체를 교체하며 각각 배치를 저장한다.
- 책의 잉크병은 저장 버튼과 같은 동작을 한다.

## 생활 화면과 일정

- 양말 짝 맞추기·빨래 정리 같은 집안일은 마을 화면에서 집안일 애니메이션과 양말 표시를 사용한다.
- 월간 일정은 열 때마다 현실의 현재 달을 기본으로 열고 오늘을 강조한다.

## 통계 보고서

- 전체 또는 마을별 범위를 선택할 수 있고 마을은 거주 인구가 많은 순서로 보인다.
- 마을·건물·캐릭터 수, 연령대와 성비 피라미드, 평균 기상·취침 시각, 평균 키·몸무게를 표시한다.
- 성격 분포 원형 그래프와 상위 3개 성격, 직업·이른 기상·사회 에너지·관계 연결 지표를 표시한다.
- 현재 선택한 보고서를 HTML 파일로 내려받을 수 있다.

## 검증

- 전용 회귀 검사로 빈 기본 사전, 정서 반응, 통계 구성, 오늘 달력, 버전과 캐시를 확인한다.
- 기존 캐릭터 정서·성능·사전 일정 검사를 함께 실행한다.

# 내부 1.0.442 (494)

## 변경
- 0.7초 정지한 보행은 현재 화면 좌표부터 기존 목적지로 이어 이동. 이번 이동이 끝나면 임시 충돌 무시 해제.
- 이동 중/가구 사용 중인 인물의 목적지에 겹침 보정을 반복 적용하지 않음. 대기 후 출발 시차를 0.7초 이내로 단축.
- 현재 보이는 방·좌표를 출발지로 사용. 자기 자신에게 내린 지시의 도착점에 출발 좌표가 섞이던 오류 수정. 가구 사용자와 방 사이 이동 캐릭터도 위치 측정 대상에 포함.
- 음식 작업은 이동→작업→복귀로 구분. 도착 후 식사 30초와 허기 회복 시작. 수면 중 자동 식사·자동 요리 방지. 정리 제목 ‘음식을 치우는 중’, 본문 ‘상태를 확인하고 음식을 치우고 있어요.’
- 사적인 방의 자동 진입을 다른 방의 휴식으로 전환. 사용자가 직접 내린 지시와 사적 활동 참여자는 예외.
- 욕구 패널의 청결 등 수치를 열린 동안 0.5초 간격으로 갱신. 화면 전체 재생성 없이 수치만 변경.
- 마을 첫 HTML에 현재 시간의 조명을 반영하여 야간 화면 갱신 중 밝아지는 현상 수정.
- 동일 자리의 겹침 위치 탐색 결과 재사용. 활동 중 좌표 흔들림과 반복 후보 탐색 감소.

## 변경 사항

- Android 태블릿 캐릭터 목록에서 캐릭터를 눌러도 오른쪽 정보 영역이 비어 있던 상태 선택 조건을 실제 캐릭터 화면 구조에 맞게 수정했습니다.
- 태블릿 가로 전체설정은 기존처럼 화면을 크게 사용하는 양면 책과 두 페이지 이동을 유지하고, 세로 화면은 큰 단면 책을 유지합니다.
- 태블릿 가로 관찰 화면과 마을 화면의 지도를 화면 전체에 채우고, 오른쪽 남색 여백과 분리 배경을 제거했습니다.
- 관찰 화면의 캐릭터 이름·직업을 프로필 사진 오른쪽에 정렬하고, Android 좌우 시스템 안전 영역 때문에 상단바 오른쪽에 생기던 빈 여백을 없앴습니다.
- 마을 캐릭터 아이콘 뒤의 흰 사각형과 장식 아이콘의 흰 배경·선택 테두리·그림자를 휴대폰과 태블릿 화면 모두에서 제거했습니다.
- Android 백업 내보내기를 시스템 파일 저장창으로 연결해 사용자가 저장 위치와 파일명을 고른 뒤 JSON 백업을 실제로 쓸 수 있게 했습니다. 취소와 저장 실패도 각각 안내합니다.
- code 232의 Android Google 로그인 복구, 첫 로그인 전 캐릭터 인계·게스트 복구본 보존, 시작 동기화와 기존 태블릿·침대 수정도 함께 포함합니다.

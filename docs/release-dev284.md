# 서랍마을 개발판 284 / 1.0.251

## 한국어
- 메인 테마 시작·복귀 음량을 부드럽게 올리고 큰 음량 피크를 완화합니다.
- 할 일 정하기에서 명령 처리 표시를 즉시 보여주고, 멀티 명령 결과를 더 빨리 반영합니다. 작은 화면 목록 스크롤과 버튼 정렬을 개선했습니다.
- 집 안에서 씻을 때 거품과 몸을 움직이는 애니메이션을 추가했습니다. 효과 강도 설정을 따릅니다.
- 최초 계정의 프로필 설정 여부를 계정에 저장하여 재설치·재로그인 때 반복되지 않도록 수정했습니다.
- 운동·병원 일정에 준비/접수, 활동/상담·검사, 마무리/수납 단계를 추가했습니다. 운동은 참가자의 기술 설정을 반영합니다. 식사·학습과 일반 일정에도 시간별 진행 장면을 적용했습니다.
- 관계 선택 스크롤의 반복 계산과 화면 이동 후 남은 처리를 줄였습니다. 전체설정은 보이는 페이지 중심으로 생성하고 페이지 이동의 즉시 저장을 줄였습니다.
- 신체 접촉 반응을 여러 개 선택할 수 있습니다.
- 귀고리·반지·목걸이·피어싱·시계·머리 장식 등 액세서리를 함께 선택할 수 있습니다.
- 전통의상은 별도 메뉴 대신 패션 분위기에서 선택합니다.

## English
- Music fades in on start/resume, with compression to soften loud peaks.
- Activity commands show progress promptly and use the multiplayer command response immediately. Improved scrolling and alignment on small screens.
- Added local washing bubbles and movement at home, respecting the effects setting.
- Profile setup follows the account's completion status rather than app installation.
- Exercise and hospital schedules progress through preparation/check-in, activities/consultation or tests, and cooldown/payment. Exercise reflects participant skills. Meals, study and general schedules also show timed progress.
- Reduced relationship selector layout work and canceled stale callbacks after navigation. Character settings build visible pages and defer page preference saves.
- Select multiple touch reactions and detailed accessories.
- Traditional attire is a fashion mood option instead of a separate menu.

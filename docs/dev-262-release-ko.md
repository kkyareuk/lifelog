서랍마을 1.0.233 개발판 업데이트 (versionCode 262)

이번 파일은 dev 기능 확인용입니다. 운영 main의 1.0.215.9 / 259와 구분됩니다. Play Console 업로드는 하지 않았습니다.

✨ 새로운 기능
- 캐릭터 이름 옆 프로필 내보내기에서 캐릭터 설정 JSON 다운로드·불러오기를 제공합니다. 불러오면 남은 슬롯에 새 캐릭터가 생성됩니다. 사진·생활 로그·타인과의 관계는 개별 설정 파일에 포함하지 않습니다.
- 같은 창에서 전체 설정 백업을 다운로드할 수 있습니다. 전체 백업은 관계와 생활 기록을 포함하며, 사진은 기기 보관 방식입니다. 복원은 기존 설정의 백업 불러오기를 사용합니다.
- 사전에 꽃·기타 물품 분류를 추가했습니다. 꽃·인형 등을 직접 등록할 수 있습니다.
- 사전 목록 위에서 사전 전체를 파일로 다운로드하거나 불러올 수 있습니다. 동일 항목을 다시 가져오면 갱신하고, 새 항목만 추가합니다.
- 신발 설정에 로퍼·비즈니스 슈즈·옥스퍼드·더비·몽크 스트랩·게타·잇폰바게타·조리·전통 신발을 추가했습니다.
- 음료 선택에 소다·모히토·무알코올 모히토·에이드·스무디를 추가했습니다.

🔧 개선 사항
- 집의 침실 방 주인과 구성원의 자는 방을 양방향으로 연결했습니다. 방 편집에서 지정하거나 구성원 주거 설정에서 지정해도 연결됩니다.
- 음료 사전의 맵기를 없애고 단맛·산미·탄산·카페인·알코올·온도 항목으로 구성했습니다.
- 사전 신규 추가 및 파일 불러오기는 종류별 80개까지 가능합니다. 기존에 80개를 넘긴 자료는 삭제하지 않습니다.

🎨 UI/UX
- 제공된 멀티 SVG의 나무 배경·뒤로가기 에셋·종이 테두리와 3열 카드 배치를 반영했습니다. 실제 그룹 이름과 참여 수를 표시하고 검색·내 그룹 필터·정렬을 제공합니다.
- 목록 안 그룹 추가 카드와 남은 마을 슬롯을 보여주는 추가 창을 마련했습니다.
- 캐릭터 유형 선택 키워드 글자를 줄이고 줄바꿈을 적용했습니다.
- 제공된 사이트 썸네일을 웹 빌드의 공유 미리보기 이미지에 반영했습니다. 운영 사이트 공개 배포는 별도입니다.

🐛 오류 수정
- dev에 있던 전체 설정 4페이지 총평의 즉시 반영·재실행 유지 수정을 이번 파일에 포함했습니다.
- 사전 저장 실패·뒤로가기 복귀·일정 종료 및 다인원 계산 부담에 대한 이전 수정도 포함합니다.

아직 포함되지 않은 기능
- 서버의 마을별 공유 사전, 공유 인테리어, 멀티 전체 생활/관계 제의/푸시, 추가 건강·복합 가족관계 설정은 이번 완료 항목이 아닙니다. 파일 교환은 직접 실행할 때만 적용됩니다. BGM은 추가 제작하지 않았습니다.

검증: 384/412px 화면, 총평 즉시 반영 및 재실행, 침실 연결, 설정 파일 왕복, 사전 80개 제한, 실제 JSON 다운로드, 멀티 검색/필터/슬롯 창, 사전 저장 실패 복구·일정 종료 회귀검사 통과. Android 빌드 완료. 실제 Galaxy 장시간 발열 및 Play 업로드는 미검증/미실행입니다.
번역 집계: 영어 2158/2846 (75.8%), 일본어 2157/2846 (75.8%).

262 추가 반영: 사전에 설정한 음료의 단맛·산미·탄산·온도·카페인·알코올을 해당 음료를 고른 카페 생활 로그에 반영합니다. 캐릭터 단맛 취향과 비교하며, 한 로그에는 최대 두 특징만 자연스럽게 씁니다. 지정하지 않은 특징은 추측하지 않습니다. 저장된 로그는 이후 사전 수정으로 바뀌지 않습니다. 혼합 재고에서도 음료만 선택합니다. 한국어·영어·일본어 문구와 실제 카페 일정 생성 검사를 통과했습니다. 신발·꽃·기타 물품의 세부 설정을 새 생활 로그에 연결하는 작업은 이번 262 범위에 포함하지 않았습니다.

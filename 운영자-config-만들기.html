운영자용 config.js 만들기

키를 코드에 직접 입력하지 않아도 돼요. 이 화면에서 완성된 파일을 내려받은 뒤 GitHub의 기존 config.js만 한 번 교체하세요.

1. Google 지도 공용 키

Google Cloud에서 웹사이트 제한과 Maps JavaScript API·Places API (New) 제한을 적용한 브라우저용 키만 입력하세요.

2. Firebase Google 로그인

Firebase 프로젝트 설정에서 보여주는 firebaseConfig 전체를 그대로 붙여넣어도 되고, 아직 만들지 않았다면 비워둬도 됩니다.

3. 토스페이먼츠

클라이언트 키만 입력할 수 있어요. 시크릿 키는 절대로 이 화면이나 GitHub에 넣지 마세요. 사업자 심사 중이므로 결제는 계속 잠긴 상태로 생성됩니다.

업로드 방법
GitHub 저장소에서 기존 config.js를 열고 연필 버튼으로 수정하는 대신, 기존 파일을 삭제한 뒤 지금 내려받은 config.js를 저장소 최상단에 업로드해도 됩니다. 이후 업데이트 압축에는 config.js가 포함되지 않습니다.

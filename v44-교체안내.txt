평행도시 v44 · 가상도시/현실 지도 선택 버전

업로드 방법
1. ZIP을 풉니다.
2. 안쪽 파일과 폴더 전부를 GitHub 저장소의 가장 바깥 화면에 업로드합니다.
3. 같은 이름의 파일은 덮어씁니다.
4. 배포 후 브라우저나 설치된 앱을 완전히 종료했다가 다시 엽니다.

주요 변경
- 관찰 화면과 설정 화면에서 “가상도시 / 현실 지도”를 선택할 수 있습니다.
- 가상도시는 Google API를 호출하지 않습니다.
- 현실 지도 모드만 Google Maps와 Places를 불러옵니다.
- 현실 지도 선택 시 현재 외출 중인 캐릭터들의 현재 장소부터 실제 장소로 확인합니다.
- 캐릭터가 가끔 감기·몸살 등으로 집에서 쉬거나 가까운 의원에 갑니다.
- 잠든 캐릭터도 관찰 상단 캐릭터 선택 목록에서는 사라지지 않습니다.
- 캐릭터 선택 상태를 다른 기기의 오래된 activeId가 덮어쓰지 않습니다.
- 선택 캐릭터의 테마를 화면을 다시 그린 직후에도 다시 적용합니다.
- 프로필 사진 입력창을 깨끗한 입력창으로 교체하여 중복 이벤트 충돌을 없앴습니다.
- 프로필 사진은 선택 즉시 로컬 저장 후 로그인 계정에 동기화합니다.

Google 현실 지도 준비
- 설정에서 Maps JavaScript API와 Places API (New)가 허용된 키를 연결합니다.
- API 키가 없으면 현실 지도 대신 설정 화면으로 안내합니다.
- 현실 지도 사용량만 Google 과금 대상이며 가상도시는 지도 비용이 없습니다.

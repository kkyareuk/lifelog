Google 실제 장소 연결

필요한 API는 정확히 2개입니다.
① Maps JavaScript API
② Places API (New)

Google 정책상 결제 계정 연결도 필요합니다. API 키는 각 사용자의 브라우저에만 저장되고 백업에는 포함되지 않습니다.
처음 발급하는 사람용 5단계 안내
  1. Google Maps Platform 시작 페이지에서 프로젝트를 만들고 결제 계정을 연결합니다.
  2. API 및 서비스 → 라이브러리에서 Maps JavaScript API를 사용 설정합니다.
  3. 같은 곳에서 Places API (New)를 사용 설정합니다. 이름에 (New)가 없는 예전 API만 켜면 검색이 실패합니다.
  4. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 누릅니다.
  5. 키 수정에서 애플리케이션 제한은 웹사이트, API 제한은 위의 두 API만 선택하고 아래 주소를 허용 웹사이트에 추가합니다.
